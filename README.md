# 以撒的竞合：冲 · 慎

当前交付目录：`web/dist-offline/`。
固定入口：`web/dist-offline/以撒的竞合.html`。

*The Bidding of Isaac: Rush & Restraint*

一款围绕 **20人共同市场、秘密报价、资源管理与连续道具构筑** 的浏览器博弈游戏。每局1名真人＋19名AI，游戏逻辑在本地浏览器中运行，无需业务后端。

当前版本 **0.5.0（本地交付，实机验收待授权）**：经典积分赛与生存淘汰赛；生存提供四档AI难度和独立教学。支持续玩、只读回放、玩家档案、基础统计及完整回放库。0.5已接入正式四阶段成就记账、当前UI档案写入同源协调、续玩去重和失败重试；浏览器缺少Web Locks时保留待处理检查点，不发放成长。**角色权限已接入：默认以撒，其余按成就或独立一键授权开放；进度页以紧凑徽章展示30项成就，提供六类／状态筛选、搜索排序、列数偏好及完整详情弹窗；六项新增仍为候选**。0.4分发未验收范围继续独立记录。

本地离线交付与资料迁移入口见[0.5.0使用与交付说明](./docs/开发/0.5.0使用与交付说明.md)。真实环境验收只在用户单独明确授权后进行；本地打包不代表发布或实机通过。

## 快速开始

需要 Node.js **22.13.0或以上**。在仓库根目录执行：

```powershell
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

打开 [本地开发页面](http://localhost:3000)。

生成可独立打开的单文件HTML：

```powershell
npm run build:offline
```

该命令会写入 `web/dist-offline/`；当前0.5交付仍使用该目录，固定入口 `以撒的竞合.html` 更新为0.5.0，旧带版本HTML保留。常规构建分发使用带版本与构建标识的HTML。对局／档案文件另行保存，通过**进度 → 存档与备份**读取。真实离线流程与文件往返的验收状态见下方文档，不以构建成功代替。
