# 以撒的竞合：冲 · 慎

*The Bidding of Isaac: Rush & Restraint*

一款围绕 20 人共同市场、秘密报价、资源管理和连续构筑展开的短局多人博弈游戏。当前原型采用 1 名真人玩家与 19 名人机玩家，全部游戏逻辑在玩家浏览器中执行。

> 本项目是非官方同人创作，与 *The Binding of Isaac* 的作者、发行商及相关权利方无隶属或认可关系。项目不会直接使用原作受版权保护的美术、音频或代码资源。

## 当前进度

- 已建立网页工程与首个房间操作界面；
- 已参数化玩家数、层级资金、房间数和扰乱倍率；
- 已实现行动合法性、等价出价和奖励资格的规则核心；
- 已加入确定性随机数基础设施和规则单元测试；
- 已确定并实现全房间共同基准线与单轮基础积分公式。
- 已确定层间资金重置、按层资金比例计算合作区宽度，以及并列随机决胜规则。
- 积分与基准线数值按四位小数保存、界面显示两位；21个人格及冲突关系均已实现，正式随机池启用20种，每名AI随机选取2～4个性格；孤注一掷暂作为可显式启用的实验人格保留。
- 已确定常见、BOSS、诅咒三类道具以及普通、稀有两档稀有度的房间抽取规则。
- 已正式记录首批 26 件道具、屏障与双行动规则，以及统一的积分和道具发放流程。
- 已实现房间与道具生成、运行时库存、双行动、整数资金、道具修正和事件化房间结算核心；界面与完整对局状态机将在后续接入。
- 已加入局势与道具感知的五行为概率 AI 决策器、均衡/合作/混乱三种主义，以及包含资金、市场、道具价值、个人最高价预测、合作区预测和 `±5%` 扰动的动态报价器。
- 高价资格按每件道具全部有效市场样本的前 20% 计算，人数四舍五入且至少 1 名；正常竞拍者占位时获得资格，扰乱者占位时轮空，超凡升天可分别赎回被扰乱占据的最高价与合作名额。
- 已加入以撒、游魂、阿撒泻勒、伊甸、雅阁和以扫五名初始角色；以撒初始携带D6并获得每层+10%资金，伊甸初始获得两件互不相同且不含福袋的随机道具并逐层随机±10%资金，雅阁和以扫获得每层+20%资金；角色资金特性不计作道具。
- 已实现“更多选择”与“更多选择?”的条件式双行动 AI：第一份行动后重新评估另一件道具、0.75积分折算、保守剩余预算和后续机会成本，并可选择停止追加；雅阁和以扫无视该0.75积分乘区。
- 已加入房间积分倍率：宝箱房 ×1.5，隐藏房与 BOSS 房 ×2；AI 的主动行为权重、机会预算、候选报价效用和双行动收益预测同步感知当前房间倍率。
- 已加入可复现的 20 AI 三层批量模拟器，并完成两轮各 5,000 局、150 万次决策的测试；第二轮包含 26 件道具的持有表现、直接效果、叠加趋势与胜率关联统计。

## 本地开发

需要 Node.js 22.13 或更高版本。

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
npm install
npm run dev
```

默认访问地址为 <http://localhost:3000>。

## 验证

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
npm test
npm run build
```

## Docker

在仓库根目录执行：

```powershell
docker compose up --build
```

随后访问 <http://localhost:3000>。容器只负责分发和渲染网页资源；对局、AI 和存档不会上传到业务后端。

停止容器：

```powershell
docker compose down
```

## Git 工作方式

`main` 分支保持可运行。功能开发建议使用短期分支，并在合并前运行测试和生产构建。版本发布使用 `v0.x.y` 格式的 Git 标签。
