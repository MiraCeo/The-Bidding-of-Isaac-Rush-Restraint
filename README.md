# 以撒的竞合：冲 · 慎

*The Bidding of Isaac: Rush & Restraint*

一款围绕 **20 人共同市场、秘密报价、资源管理和连续道具构筑** 展开的短局博弈游戏。当前可游玩原型采用 **1 名真人玩家 + 19 名 AI**，全部对局与 AI 逻辑在玩家浏览器中执行，不需要业务后端。

> 本项目是非官方同人创作，与 *The Binding of Isaac* 的作者、发行商及相关权利方无隶属或认可关系。当前26件道具均已使用用户提供的收藏道具／饰品／掉落物图片，见 [图标映射](./道具图标接入_v1.md)。

| 项目 | 当前口径 |
| --- | --- |
| 对局 | 20 人，三层各五房，共 15 房 |
| 基础资金 | 100 / 500 / 1000；换层重置资金，保留积分和道具 |
| 核心行动 | 正常竞拍、扰乱市场、静观其变；竞与合是正常竞拍的不同目标 |

| 奖励 | 每组高价前 20% 与合作区最近的一半；扰乱占位轮空，重复资格不顺延 |
| 房间倍率 | 普通／商店 ×1，宝箱 ×1.5，隐藏／BOSS ×2 |
| 构筑 | 五个角色、26 件道具、屏障、条件式双行动与终局王冠结算 |
| AI | 均衡 9、合作 5、混乱 5；五行为概率决策、公开历史与动态报价 |
| 人格 | 已实现 21 种，正式随机池 20 种；每名 AI 2～4 种，孤注一掷仅实验启用 |
| 随机 | 可注入种子；行为权重扰动 ±10%，报价通常 ±5%、赌徒 ±15% |
| 数值 | 资金为非负整数；积分与基准线保存四位小数、通常显示两位 |

## 本地开发

需要 Node.js 22.13 或更高版本。技术栈为 React 19、TypeScript、Vite、Tailwind CSS 与 Vitest。

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
npm install
npm run dev
```

默认访问 [http://localhost:3000](http://localhost:3000)。

## 单文件 HTML 离线验收

改完代码后执行一次，不需要持续启动开发服务：

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
npm run build:offline
```

生成 [以撒的竞合.html](./web/dist-offline/以撒的竞合.html)。在文件夹中用浏览器打开该文件；分发时只发送这一个 HTML，无需附带 `assets`、Node.js 或 Docker。固定入口每次覆盖同名文件，同时生成带版本／构建标识的分发HTML及清单。产物不进入Git，完整交付使用 `npm run build:release`，见 [交付说明](./新手教程与版本交付_v1.md)。

这不是界面截图，而是使用正式入口与规则的完整客户端。代码改动后需要重新构建；浏览器允许时刷新恢复本局，也可从设置读取JSON存档。正常 `npm run dev`、`npm run build` 和 Docker 流程不变。

构建门禁和真实浏览器验收是两项不同的检查；离线浏览器自动验收按用户要求跳过，不作为后续功能开发的前置条件。后续按“修改源码→测试→验收前构建→用户界面／游玩反馈→修正”推进。详细记录见 [离线构建与验收](./离线HTML构建与验收.md)。

## 验证与模拟

### 规则测试与生产构建

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
npm test
npm run build
```

生产构建先运行 TypeScript 类型检查，再输出静态资源至 `web/dist`。未设置对应局数环境变量时，报告型大批量模拟测试默认跳过；普通规则和客户端测试仍会运行。

### 通用 19 AI 混合模拟

```powershell
Set-Location -LiteralPath 'D:\The Bidding of Isaac\web'
$env:SIM_GAMES = '5000'
$env:SIM_SEED = '20260908'
$env:SIM_AI_COUNT = '19'
$env:SIM_DISTRIBUTION = '9,5,5'
$env:SIM_SITUATION = '1'
$env:SIM_ITEMS = '1'
$env:SIM_PERSONALITIES = '1'
$env:SIM_PERSONALITY_MIN = '2'
$env:SIM_PERSONALITY_MAX = '4'
$env:SIM_DOUBLE_ACTIONS = '1'
npm run simulate
```

这运行的是无真人的 19 AI 统计实验，不是 1 真人 + 19 AI 的客户端对局。`npm run simulate` 未设置 `SIM_GAMES` 时不会自动执行 5,000 局。以上环境变量仅作用于当前 PowerShell 会话。

### v23 三组人格池对照入口


## 本地 Docker

完整交付包可在 `web` 目录执行 `npm run build:deployment` 生成：同版本网页、离线下载、文件证据和直接复制已验证网页的镜像上下文。未提交代码可生成开发预览，但严格远端发布会拒绝；不会因执行构建命令自动上线。

仓库已经包含多阶段Dockerfile、Compose端口映射与Nginx配置；本地版本交付与T11发布准备已实现，首次远端／容器运行验收仍待执行。CI默认只校验，Pages／镜像／草稿Release仅手动触发，见 [发布准备](./云发布与分发准备_v1.md)。当前以电脑端优化为主，移动端明确后移。

在仓库根目录执行：

```powershell
docker compose up --build
```

随后访问 [http://localhost:3000](http://localhost:3000)。容器负责分发静态网页；对局、AI 和随机状态仍在浏览器中执行。浏览器允许时自动保存并在刷新后恢复对局；可携带的JSON文件用于跨地址／浏览器继续游戏。

停止容器：

```powershell
docker compose down
```
