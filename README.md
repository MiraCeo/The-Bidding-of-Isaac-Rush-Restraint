# 以撒的竞合：冲 · 慎

*The Bidding of Isaac: Rush & Restraint*

一款围绕 **20人共同市场、秘密报价、资源管理与连续道具构筑** 的浏览器博弈游戏。每局1名真人＋19名AI，游戏逻辑在本地浏览器中运行，无需业务后端。

当前开发预览 **0.5.0**：经典积分赛与生存淘汰赛；生存提供四档AI难度和独立教学。支持续玩、只读回放、玩家档案、基础统计及完整回放库。0.5已建立30项成就规则层、精确评分证据、成长账本及后台保存协调；**尚未接入正式对局自动发奖、成长迁移、成就UI或角色限制，当前五角色仍可选**。0.4分发未验收范围继续独立记录。

## 快速开始

需要 Node.js **22.13.0或以上**。在仓库根目录执行：

```powershell
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

打开 [本地开发页面](http://localhost:3000)。

生成可独立打开的单文件HTML：

```powershell
npm run build:offline
```

输出位于 `web/dist-offline/`；分发使用带版本与构建标识的HTML。对局／档案文件另行保存，通过**进度 → 存档与备份**读取。真实离线流程与文件往返的验收状态见下方文档，不以构建成功代替。
