*The Bidding of Isaac: Rush & Restraint*

一款围绕 **20人共同市场、秘密报价、资源管理与连续道具构筑** 的浏览器博弈游戏。每局1名真人＋19名AI，游戏逻辑在本地浏览器中运行，无需业务后端。

当前版本 **0.5.11（本地交付，实机验收待授权）**：经典积分赛与四档AI难度生存淘汰赛，支持续玩、只读回放、玩家档案和完整回放库。成就现有**107枚徽章／57张卡片**、25组单卡三级，分类按卡片计数并随筛选联动，卡片默认显示最高已获等级，指定金级不借铜级已获状态；总览仍按真实徽章统计；六分类、铜银金、隐藏、札记与保存后通知。屡败屡战改为正式终局第6及以后5／10／20局，游魂仍需非将军之过＋新一级；0.5.11用固定基线清理未标记旧成就及其派生权限，手动一键授权保留；新基线后正常累计与继承。C～F补齐10组三级，鸠占鹊巢1／10／20、时来运转6／18／66，反客为主需同局两房实际交付；旧数据清理已接入启动／恢复链路，全局重编号仍列TODO，不关闭正常继承。B10／E13／E14／F11仍暂缓。不改变竞拍、道具、AI或生存规则；成长保存继续使用同源协调，未成功不虚报入账。

本地离线交付与资料迁移入口见[0.5.x使用与交付说明](./docs/开发/0.5.0使用与交付说明.md)。真实环境验收只在用户单独明确授权后进行；本地打包不代表发布或实机通过。

## 快速开始

需要 Node.js **22.13.0或以上**。在仓库根目录执行：

```powershell
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

打开 [本地开发页面](http://localhost:3000)。

生成可独立打开的单文件HTML：

```powershell
npm run build:offline
```

该命令会写入 `web/dist-offline/`；当前0.5交付仍使用该目录，固定入口 `以撒的竞合.html` 随当前版本更新，旧带版本HTML按0.2／0.3／0.4系列子目录归档，根目录保留当前0.5.x与固定入口／当前配套清单。常规构建分发使用带版本与构建标识的HTML。对局／档案文件另行保存，通过**进度 → 存档与备份**读取。真实离线流程与文件往返的验收状态见下方文档，不以构建成功代替。
