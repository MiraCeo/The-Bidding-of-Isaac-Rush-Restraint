*The Bidding of Isaac: Rush & Restraint*

一款围绕 **20人共同市场、秘密报价、资源管理与连续道具构筑** 的浏览器博弈游戏。每局1名真人＋19名AI，游戏逻辑在本地浏览器中运行，无需业务后端。

当前版本 **0.6.1（工具页与成就信息精简，实机验收待授权）**：经典积分赛与四档AI难度生存淘汰赛，支持续玩、只读回放、玩家档案和完整回放库。成就现有**107枚徽章／57张卡片**、25组单卡三级；分类卡片计数随筛选联动，默认展示最高已获等级。正式编号按分类连续、同系列铜银金相邻，分段成就改为具体触发条件；[成就总表](./docs/规划/成就总表.md)与[编号对照](./docs/规划/0.5成就编号对照.md)已同步。固定基线1后进度与权限正常继承，旧提案4项继续暂缓；收藏札记整理列后续TODO。不改变竞拍、道具、AI或生存规则；成长保存使用同源协调，未成功不虚报入账。

0.5远端开发收口与精确提交CI见[核验记录](./docs/记录/0.5开发收口与远端CI核验.md)。当前0.6只优化已有界面与性能，首批独立档案核验复用见[性能记录](./docs/记录/0.6.0独立档案核验复用与性能对照.md)，工具页HUD与成就信息精简见[0.6.1记录](./docs/记录/0.6.1工具页HUD与成就信息精简.md)，不新增功能；0.5的push授权不自动沿用。

本地离线交付与资料迁移入口见[0.5.x使用与交付说明](./docs/开发/0.5.0使用与交付说明.md)。真实环境验收只在用户单独明确授权后进行；本地打包不代表发布或实机通过。

## 快速开始

需要 Node.js **22.13.0或以上**。在仓库根目录执行：

```powershell
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

打开 [本地开发页面](http://localhost:3000)。

生成可独立打开的单文件HTML：

```powershell
npm run build:offline
```

该命令会写入 `web/dist-offline/`；当前0.6交付使用该目录，固定入口 `以撒的竞合.html` 随当前版本更新，旧带版本HTML按0.2／0.3／0.4／0.5系列子目录归档，根目录保留当前0.6.x与固定入口／当前配套清单。常规构建分发使用带版本与构建标识的HTML。对局／档案文件另行保存，通过**进度 → 存档与备份**读取。真实离线流程与文件往返的验收状态见下方文档，不以构建成功代替。
