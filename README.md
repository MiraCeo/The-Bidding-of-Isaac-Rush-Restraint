## 快速开始

需要 Node.js **22.13.0或以上**。在仓库根目录执行：

```powershell
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

打开 [本地开发页面](http://localhost:3000)。

生成可独立打开的单文件HTML：

```powershell
npm run build:offline
```

该命令会写入 `web/dist-offline/`；当前0.7交付使用该目录，固定入口 `以撒的竞合.html` 随当前版本更新，旧带版本HTML按0.2／0.3／0.4／0.5／0.6系列子目录归档，根目录保留当前0.7.x与固定入口／当前配套清单。常规构建分发使用带版本与构建标识的HTML。对局／档案文件另行保存，通过**进度 → 存档与备份**读取。真实离线流程与文件往返的验收状态见下方文档，不以构建成功代替。
