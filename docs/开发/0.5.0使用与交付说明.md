## 二、使用入口

解压到自选目录，保留说明与校验文件；离线程序本身是一个HTML，可由用户在浏览器中打开。此处是使用说明，本轮没有执行打开／试玩／下载导入验收。不要把源码目录旧`web/dist-offline/以撒的竞合.html`误认为本次0.5包，该历史固定入口仍保留0.4.11。

| 入口 | 用途 |
| --- | --- |
| 主菜单→经典模式／生存模式 | 选择模式与角色，开始正式对局 |
| 进度→成就 | 六类30项成就、已保存进度与时间、角色解锁前置；同局型显示历史单局最高记录 |
| 选角页或进度→成就→一键解锁全部角色 | 只保存角色授权，不完成成就、不增加统计进度 |
| 进度→存档与备份 | 续玩、回放、本局完整备份、独立玩家档案的导出／读取与确认 |
| 进度→对局记录→长期完整回放库 | 完整回放与整库备份／恢复；不等同最近200条轻量完成记录 |
| 设置／规则 | 显示偏好、版本说明、规则与独立教学 |

默认角色为以撒。游魂需要“非将军之过＋屡败屡战”；阿撒泻勒需要“厚积薄发＋硫磺火？”；伊甸需要“神秘礼物”；雅阁和以扫需要“我全都要”。已有合法旧局可沿用原角色继续，教学与AI不受选角权限限制。

## 三、旧资料与文件边界

- 存档保存在浏览器来源中，不写入HTML。复制或移动HTML不等于迁移玩家资料，不保证不同路径、协议或浏览器共享自动存储。
- 旧程序中的资料需由用户另行导出，再在新程序的对应入口读取。只读取当前v5对局；v2／v3／v4不迁移。原JSON与压缩容器1按现有入口识别。
- 新读取器可读缺少growth字段的旧v5，但带growth1的新检查点不能交给旧0.4读取器。档案正文1、独立档案备份1和整库备份1是不同用途的协议。
- 不依据0.4历史补发成就；旧预留解锁字段不直接作为0.5角色权限。恢复既有0.5权限不在普通重载时重新锁定；明确恢复更早档案允许成就、进度与角色权限回到快照，不自动合并被替换成果。
- 文件预览／只读回放／重复恢复不额外发奖。完整备份默认只载入对局，替换档案需按界面明确确认；独立档案不包含两模式续玩位置、完整库或设置。
- 成长保存需要浏览器提供Web Locks协调能力；缺能力时保留待处理进度并说明，不显示虚假的已入账。gzip读取也受浏览器解压能力约束。
- 保存失败时区分检查点与成长／配套保存状态，保留当前内存局并提供重试；需要保留未保存对局时，先按界面导出，不把重新选角当成备份。
