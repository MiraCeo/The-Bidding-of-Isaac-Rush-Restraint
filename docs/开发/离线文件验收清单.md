## 3. 取消、错误与重复

- [ ] 选择文件后先预览，取消／返回不安装候选；更换文件清空上份恢复档案选择。
- [ ] 当前原JSON／压缩.json均可读取；损坏／超限／旧v2／v3／v4明确失败，原数据保留。
- [ ] 重复恢复／只读回放不增加完成累计或等价库记录；不同真实分支保留。
- [ ] 档案旧预览期间来源改变，确认被阻止；重新核对后需重新勾选。
- [ ] 整库新增／重复／删除保护与最后核对后原子追加；取消／失败不部分提交。
- [ ] 保存额度不足等异常记录检查点／回放／档案的各自状态，不把临时UI成功当完整落盘。
