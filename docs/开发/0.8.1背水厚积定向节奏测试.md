- main：6个独立种子序列块，每块连续20局、3种脚本、6个场景，共2160局、108条新档路径。
- 场景：正式classic-population-1的4档、旧classic-tiered-1标准对照、未改变的role-aware-1标准生存参照。每场景18条路径来自6个独立种子块；相关脚本不当独立真人。
