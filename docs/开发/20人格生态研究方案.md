## 一、顺序

1. 统计口径与固定实验输入。
2. 区分扩池抽样结构与新增五人格效果。
3. 逐人格消融和三组合法人格组合。
4. 只改变赌徒报价噪声，保留人格抑制。
5. 只改变双行动17%安全上限的资金基准。
6. 建立道具扩充准入清单与自动化元数据测试，不新增道具。

## 二、统计口径

- `initialRoomScore`：奖励发放前的原始房间积分。
- `retroactiveRoomScore`：新取得心脏的追溯追加。
- `finalRoomScore`：前两者之和，不包含终局王冠。
- 整局 `finalScore`：包含终局王冠，不能与房间最终分混为同一口径。
- 旧 `roomScore`、双行动 `actualRoomScore`、`scorePerActualMoney` 保留原定义，新增字段不回写历史数据。
- 新 `finalScorePerActualMoney` 使用追溯后总收益／总实际扣款；返款另行解释，不把可能为零或负数的净支出直接用作分母。
- 合并种子时按样本数合并均值和方差；P05/P50/P95/P99保留每种子的真实分位，不把平均分位数标为合并分位。

## 三、固定输入与实验开关

每个种子和局号固定房间、角色、初始库存、主义、个人报价档案和各层角色资金。20人格各组固定抽样结果、人数和冲突关系；只将指定人格从生效列表移除，原始人格标签保留用于统计携带者，不能重抽槽位。

策略与报价采用玩家／房间独立随机流，入房与结算采用房间独立流；记录世界与人格诊断指纹。不同条件下的结算内部判定仍可能消耗不同数量的随机数，因此是固定外生输入的干预对照，不宣称逐次判定完全配对。

统计“关闭某性格后同一携带者群体变化”而不是拿两个不同携带群体直接比较；结果仍包含共同市场外部性，不把它解释成脱离生态的性格强弱等级。

## 四、本轮14个条件

| 条件 | 唯一改变／用途 |
| --- | --- |
| original15 | 历史15种作为抽样结构对照，不修改正式池 |
| neutral20 | 正式20种保持槽位，适应／理智／傲慢／固执／赌徒效果中性化 |
| formal20 | 现行20种完整效果，研究控制组 |
| adaptive_off | 仅关闭适应 |
| rational_off | 仅关闭理智 |
| arrogant_off | 仅关闭傲慢 |
| stubborn_off | 仅关闭固执 |
| gambler_off | 关闭赌徒的抑制与噪声，用于完整效果消融 |
| adaptive_rational_off | 联合关闭适应＋理智，分析合法组合交互 |
| rational_stubborn_off | 联合关闭理智＋固执 |
| arrogant_stubborn_off | 联合关闭傲慢＋固执 |
| gambler_noise05 | 赌徒噪声改±5%，其余效果保留 |
| gambler_noise10 | 赌徒噪声改±10%，其余效果保留；±15%由控制组提供 |
| character_budget | 仅将双行动实际成本上限的17%基准改为已记录的角色层初始资金 |

每个条件已跑种子 `20260908`、`20261010`，每种子2,000局。每组4,000局、76,000份玩家记录；14组共56,000局、1,064,000份记录、15,960,000次主决策。

neutral20与formal20比较新效果；original15与neutral20比较旧人格覆盖及冲突／槽位结构变化。联合消融交互仅在原档案同时携带两个人格的固定群体中计算，不能把“同时出现”当作已经证明协同。

## 五、双行动预算的隔离

实验读取 `characterFloorStartingMoney`：角色资金特性执行后的真实整数资金，早于利息。伊甸每层只抽一次，不在报价阶段重抽。不把利息增长、偷钱袋或当前剩余资金当作角色初始资金。

只调整 `min(0.4money, 0.17F)` 的第二项基准；名义总额40%、公共储备10%、停止权重3、真人合法性及雅阁和以扫积分被动均不变。实验设置不会自动进入正式客户端。

## 七、T08角色资金专项（2026-10-12）

新增独立运行器 [character-budget-research.ts](../../web/lib/game/character-budget-research.ts)，不改原14条件、默认模拟或正式客户端。每种子2,000局，种子为 `20260908,20261010,20261011,20261012`，三组共24,000局：公共资金预算、角色资金预算、关闭AI双行动。前两组仅改变17%实际总扣款安全上限的资金基准；关闭双行动组用于机制消融，不是拟发布规则。

- 沿用19 AI、9/5/5主义、2～4人格、正式20人格池和玩家／房间独立随机流；孤注一掷仍不进入样本。
- 核对每个种子的世界、人格档案指纹和每层资金分组；角色资金不含利息，不在报价时重抽。
- 雅阁和以扫关注整局均分、个体冠军率相对于1/19的表现、配对胜率差，以及三层资金健康和双行动。
- 伊甸按每层已取整初始资金相对本层公共资金分为低／相等／高，保留取整后恰好相等的一组；下一层重新分组。不按剩余资金或任意一层标签归因整局冠军。
- 逐层记录最终房分（含当前房心脏追溯、不含终局王冠）、层末资金、实际扣款、进入商店／BOSS前无资金率、第4／5房入场无资金率、观望和双行动资格／选择／收益。
- 双行动均分与收益是已选择双行动样本的描述性统计；不能将它与单行动均分差直接当作一次追加行动的因果收益。关闭双行动对照会改变共同市场，结果包含生态外部性。
- 角色整局均分和冠军率差用固定同局角色群体配对；每局是一个统计簇，95%区间使用整局簇级残差，不将同局19名玩家当独立样本。跨种子按计数合并，不平均命中率或标准差。
- 诊断开关不改变既有结果；关闭双行动后，公共／角色预算开关作为完全一致的负对照。所有实验开关保持默认关闭。

## 八、T07／T09同步研究（2026-10-12）

新增 [联合运行器](../../web/lib/game/noise-ecology-research.ts) 和 [只读观测器](../../web/lib/game/noise-ecology-diagnostics.ts)，T09复用T07的完整对局，而不是再开一组不同输入的模拟。

- 六个种子：`20260908,20261010,20261011,20261012,20261013,20261014`，每种子每条件1,000局。
- 两条件：正式赌徒±15%与候选±10%，保留人格抑制、正式公共双行动预算、其他人格和资金规则。
- 三环境：19 AI玩家／房间独立随机流；真实客户端20槽位＋固定竞拍脚本；真实客户端20槽位＋固定观望脚本。总计36,000次运行、684,000份AI记录、10,260,000次AI主决策。
- 客户端组直接使用 `startClientGame`、正式状态机、实际每房共享的策略／报价流、入房与结算流；只显式注入原报价噪声实验参数。正式两参数reducer不接收实验设置，存档状态不增加实验字段。
- 固定竞拍脚本使用当前资金／本层剩余房间数取整，正资金至少出1，交替选择A／B；不看隐藏道具、其他玩家秘密行动或未来结果。真人角色按五角色轮换，每种子各200局。脚本不是真人试玩，也不代表所有玩家策略。
- 实际客户端不同于独立流模拟：候选可以通过条件分支改变后续AI对同一房共享报价随机流的消耗；只核对外生世界与原始携带者，不宣称各玩家后续随机判定都一一配对。
- 赌徒主报价与已提交第二报价分别记录裁剪率；合作区命中使用市场等价，另记实际合作名额。v26的旧合作命中观测使用计分等价，保留旧数据，不将新旧比例直接拼接作参数收益。
- T09记录每层BOSS参与／无资金／原始、追溯与最终房分；第4／5房入场无资金率；整局P05／P50／P95／P99；终局前分与终局分；按0／1／至少2份心脏分组；各主义个体冠军率及AI冠军份额。玩家脚本冠军单独记账。
- 汇总分位数从各种子的原始分数合并后重新计算，不平均分位数；各比例从原始分子／分母合并。赌徒均分与冠军率差采用整局簇级配对区间。
- 心脏持有与冠军的关系只作构筑相关性，不以高分尾部或持有者均分差直接证明道具因果强度，不以降低标准差为目标。
- 同时保留五角色整局统计与每层第4／5房无资金计数，覆盖T08遗留的雅阁和以扫观察；角色分组和全场计数必须相加一致，不用全场均值掩盖角色差异。
