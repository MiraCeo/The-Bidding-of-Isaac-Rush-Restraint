# 开发与验证

更新日期：2026-10-15。技术栈React 19、TypeScript、Vite、Tailwind CSS、Vitest；Node.js要求以`web/package.json`为准，当前至少22.13.0。命令均使用仓库现有锁定工具，不临时升级依赖。

## 当前授权边界

- 真实环境验收须用户单独明确授权：不自行打开浏览器试玩、直接file、多页面竞争或真实下载／导入，不将一般开发／整批推进／本地打包授权当作实机授权。
- 无实机授权时只做源码、类型／lint、单元／自动化DOM、构建、静态契约、哈希／归档完整性和文档核对；不因需要留证而自行启动预览服务或改变浏览器权限。
- push、部署、发布、合并和打标签均待明确命令；当前用户允许适时本地commit及0.5.0本地打包。
- 当前离线使用与数据迁移见[0.5.0交付说明](./0.5.0使用与交付说明.md)，当前离线输出为`dist-offline`，重建时更新固定入口并保留旧带版本归档。

## 本地开发

```powershell
# 从仓库根进入前端目录
Set-Location -LiteralPath '.\web'
npm ci
npm run dev
```

开发页面默认[localhost:3000](http://localhost:3000)。AI和对局在浏览器运行，Vite不是业务后端。临时自动复验服务仅绑定127.0.0.1，验收后停止。

## 日常验证

在`web/`中顺序执行：

```powershell
npx --no-install tsc --noEmit
npm run lint:client
npm test -- --maxWorkers=4
npm run build
npm run build:offline
npm run verify:offline
```

- 类型检查、lint、规则／交互回归、构建与真实页面验证是不同证据。
- 报告型批量测试默认跳过；不要为了通过而关闭已有普通回归或放宽事实校验。
- CPU较重的完整回归与研究顺序运行，避免叠加；4 workers是当前验收的资源控制，不是游戏参数。
- 运行完整测试期间不改源码，防止部署测试核对源码指纹时混入中间状态。
- 证据放`web/work/`；TS源码快照用`.ts.txt`保留，避免被宽范围tsconfig当成项目源码。
- 本轮可用`node web/scripts/check-doc-links.mjs`从仓库根检查本地文档链接与归档JSON换行；也可从`web/`执行`node scripts/check-doc-links.mjs`。命令不验证远端URL或页内锚点。

## 网页与离线包

`npm run build`输出`web/dist/`。`npm run build:offline`输出`web/dist-offline/`的单文件HTML、带版本HTML、manifest和SHA256；旧带版本包保留，固定别名更新。

`npm run verify:offline`只读核对dist-offline的版本／归档／固定入口／manifest／SHA256／说明及当前文档入口，不构建、不打开浏览器、不写文件，也不将清单中的历史验证记录当作新门禁。

构建后核对应用版本／内容标识。普通build成功不是完整release／deployment门禁；manifest验证字段未填时不冒充门禁通过。直接file、实际下载落盘、恢复和HTTP视觉复验分别记录，见[离线构建](./离线HTML构建与验收.md)、[离线验收清单](./离线文件验收清单.md)及[最终流程复验](../记录/0.4完整流程复验与最终收口_v54.md)。

当前交付使用上方`npm run build:offline`。下列release／deployment脚本是历史或独立发布工具，不是0.5当前离线打包流程，也不应为了打包自动调用：

```powershell
npm run build:release
npm run build:deployment
npm run prepare:deployment
```

这些命令不会让云发布自动验收。CI／手动发布配置在`.github/workflows/`；具体范围见[发布准备](./云发布与分发准备_v1.md)。

## 模拟研究

以下是无真人的19 AI实验，不等同正式20人客户端或真人体验：

```powershell
$env:SIM_GAMES = '5000'
$env:SIM_SEED = '20260908'
$env:SIM_AI_COUNT = '19'
$env:SIM_DISTRIBUTION = '9,5,5'
$env:SIM_SITUATION = '1'
$env:SIM_ITEMS = '1'
$env:SIM_PERSONALITIES = '1'
$env:SIM_PERSONALITY_MIN = '2'
$env:SIM_PERSONALITY_MAX = '4'
$env:SIM_DOUBLE_ACTIONS = '1'
npm run simulate
# 研究结束后清除本会话局数开关，避免日常测试误触发大批模拟
$env:SIM_GAMES = $null
```

通用模拟未设置SIM_GAMES时不会自动执行5000局。专项种子、局数、条件和原参数读对应归档报告，不把历史命令默认启用到正式客户端。方法见[20人格研究方案](./20人格生态研究方案.md)，数据见[研究归档](../归档/早期研究/README.md)。

## Docker与Git

在仓库根使用现有`Dockerfile`／`compose.yaml`／`nginx.conf`：

```powershell
docker compose up --build
# 停止本地容器
docker compose down
```

容器仅分发静态网页；当前容器运行和真实云URL仍单列未验收，不把工程配置视为已部署。

当前分支和提交以Git记录为准，不把旧0.2的基线称为当前HEAD。新分支默认`codex/`前缀；仅按明确请求commit、push、合并、打标签或部署。文档整理不顺带调AI／规则或回写旧包来源。
