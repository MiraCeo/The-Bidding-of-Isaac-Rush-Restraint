## 路线与样本

- pilot：1个独立种子序列×3路线×4局，共12局，仅检查真实跨模式累计与投影，不合入主样本。
- main：6个独立种子序列×3路线×30局，共540局、18份单档路径。每条从以撒新档开始，只用生产档案实际解锁的角色。
- 第1～20局交替经典／生存，恰好各10局；第21～30局按候选缺项选择模式。记录20／25／30局的完整117项覆盖、最后缺项与截尾。
- 路线public使用原公开信息强脚本；mixed在原均摊／探索脚本间按固定规则切换；collector根据已解锁角色、未体验角色、角色专属缺项选择角色，经典冠军未获时可用简单档，扰乱机会可用原探索脚本。生存先标准、再困难／最高，针对最低存活用已固定公开压线脚本，最低后冠军用首层压线、后续公开强脚本的固定混合。
- 决策只用当前公开状态、已获记录及未达目标；不读本房对手报价、平局随机数、未来奖励或未解锁角色。结算后的道具持有／奖励机会仅作观察，不能反喂本房决策。没有人工发奖、额外道具或收入。

种子：main索引25000～25179，pilot24900～24903，公式`(0x08010000 + Math.imul(index + 1,104729)) >>> 0`，独立于前轮研究。3路线共享种子序列，但角色、难度和后续轨迹可自然分叉。

## 什么能证明、不能证明

一份**真实旧规则成长档案**提供权威进度；未改门槛项沿用生产已获标记，改次数的28项才比较候选数值。投影不改变真实达成时间／解锁／收据，也不回写玩家文件。每局断言候选解锁能力与真实能力一致，保存上下文、旧档案与只读投影的独立哈希。

原规则与候选是在同一实际路线上的门槛对照，不是两套分别优化到极限的收集策略。若某项旧条件本身难以触发，不能因为调低其他次数就宣称全成就目标已达；平均获得110枚也不等于117枚完成。

记录每条路径首次全117局数，未完成明确截尾；原规则因35局硬下限不可能在30局全部完成。分析第20／25／30局的达成数、完整完成率、缺项频次、实际角色／难度机会和道具暴露。若仍被旧高累计或稀有单局条件卡住，先报告具体阻塞，不自动追加新的门槛修改。
