# 角色系统 v1

> 状态：现行角色规则。核对日期：2026-10-10。以当前代码及 v20 角色资金方案为准；v19 的以撒完整利息构筑是历史实验，不是当前初始配置。

## 定位

0.3开发补充：经典伊甸随机池仍仅排除福袋；生存伊甸额外排除黑王子之冠，适用于真人和AI。固定初始道具、角色资金特性与经典随机流不变，见 [0.3实施记录](../归档/0.3/0.3生存模式实施记录.md)。

角色决定玩家进入对局时的初始道具，与主义和性格相互独立。每名 AI 必须且只能选择一个角色。当前 AI 在五名角色中等概率随机选择，使用独立、可复现的随机源；后续可以再加入角色偏好或房间配置权重。

## 首批角色

| 角色 | 初始道具 |
| --- | --- |
| 以撒 | 六面骰（D6）；每层初始资金增加10% |
| 游魂 | 神圣屏障、永恒六面骰 |
| 阿撒泻勒 | 硫磺火 |
| 伊甸 | 从当前完整道具目录中随机获得两件互不相同的道具，福袋除外；每层初始资金在基础值的90%～110%之间独立随机 |
| 雅阁和以扫 | 更多选择、更多选择?；无视“更多选择”系列的0.75双行动积分乘区；每层初始资金增加20% |

## 实现规则

- 初始道具在第一层第一房前进入库存，并通过与房间奖励共用的授予函数生成屏障；伊甸初始木质十字架已经可以保护第一房，修复记录见 [D07](../归档/0.2/文档与实现差异.md)。
- 游魂的神圣屏障在每层开始时正常生成一层临时屏障。
- 伊甸的两件初始道具分别从当前完整道具目录中无放回抽取，因此不会相同；可以随机到常见、BOSS或诅咒道具，也可以随机到普通或稀有道具，唯一排除项为福袋。
- 以撒每层资金重置时获得基础初始资金的 `110%`；雅阁和以扫获得 `120%`；伊甸每层独立抽取 `[90%, 110%]` 的连续倍率并将资金四舍五入为整数。
- 角色资金特性只修改玩家进入该层时实际获得的资金。共同基准线常量、σ、合作区宽度、AI基础定价等公共规则仍以全房间统一的层初始资金 `100/500/1000` 计算。
- 资金处理顺序为“公共层初始资金→角色资金特性→利息层间加成→利息房间加成→其他房间经济效果”。
- 角色特性不是道具，不生成道具实例，不计入道具数量，也不会降低黑王子之冠的得分加成。
- 初始道具计入最终持有道具数量和持有者表现，但不计入房间道具出现次数或竞拍发放次数。
- 雅阁和以扫同时满足双竞拍与双扰乱的持有条件；AI 会在第一份行动后根据保守剩余预算、第二件道具价值、积分折算、资格概率和机会成本决定是否追加同类的第二份行动。AI 追加时还必须保留下一房间储备，并遵守双行动名义报价与预计实际扣款上限。
- 雅阁和以扫执行双竞拍或双扰乱时，两份行动积分直接相加，不应用“更多选择”或“更多选择?”通常具有的 `×0.75` 房间积分乘区；其他角色仍正常应用该乘区。
- 角色随机、伊甸初始道具随机均可通过种子复现。
- 伊甸每层资金倍率也由可复现的随机源生成，各层分别重新抽取。

客户端真人从角色选择页指定角色，19 名 AI 独立随机；AI 的角色、主义和人格相互独立。角色资金特性不改变公共层基础资金，也不把个人额外资金纳入 AI 双行动的 `17%F` 公共上限。

运行时保存角色修正后、利息前的 `characterFloorStartingMoney`，伊甸每层仅抽一次。v26仅在独立实验中用该值作为17%基准，正式客户端仍使用公共资金；这不是新的角色补偿。

## 统计口径

现有模拟器记录五名角色的样本数、五类行为比例、平均积分、平均资金、平均道具数、个体冠军率和房间发放表现；冠军与全体玩家分位记录保存角色字段。具体统计结论按各报告实验规则理解，不以 v19 历史角色参数替代现行 v20 方案。
