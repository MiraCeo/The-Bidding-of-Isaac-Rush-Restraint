# 玩法概览

更新日期：2026-10-20；当前0.8.0本地交付版，本次只改成就文案与展示、不改玩法。本页用于快速理解玩法；具体道具与计分以当前规则、代码和下方规范为准，历史模拟报告不直接覆盖正式参数。

## 两种模式

| | 经典模式 | 生存模式 |
| --- | --- | --- |
| 开局 | 1名真人＋19名AI | 1名真人＋19名AI |
| 流程 | 三层，每层五房，共15房 | 每层五房，逐层淘汰，正式最多七层 |
| 目标 | 积分与构筑，终局按正式最终分排行 | 尽量存活，再比较累计新增积分 |
| 层末 | 正式换层规则与角色资金 | 余额兑换、继承与淘汰；每层至少淘汰两人，剩余不超过六人结算 |
| AI | 正式20人格池；简单／标准／困难／最高，默认最高（原版），开局后锁定 | 简单／标准／困难／最高，默认标准，开局后锁定 |
| 特殊边界 | 保留经典道具与终局倍率 | 不使用黑王子之冠；真人提前淘汰后AI自动完成整局 |

生存正式斩杀线：**200／325／500／750／1050／1500／2500**。历史曲线只是实验，不能用旧报告替换当前设置。

## 一房如何进行

1. 选目标，进行竞拍、扰乱或明确观望；角色／道具决定能否双行动。
2. 提交之前各玩家报价保密，AI只读取公开局势和已结算历史；问号奖励不提前公开。
3. 所有行动形成共同市场，结算积分、占位／资格、实际道具与资金，再进入下一房。

名义报价、实际扣款、市场等价、计分等价是四种数值。折扣不提高名义上限，双行动贡献两个市场样本，合作区参数表示半径，不是整个区间宽度。

## 排行与记录

经典公开排行与结算积分／争夺榜分开。生存榜显示玩家、状态、各层分数与累计分数；存活者先于淘汰者，淘汰层更高者在前，再按累计分排序。当前层只累计已结算房间，现金到层末才兑换，继承不重复计入新增累计。
