## 原问题与处理

1. 顶栏原用76vw，工具页面用92vw／1480px，成就又单独限制1200px，出现品牌、页面标题和内容的多重左边线；菜单版本胶囊又占满网格剩余列。
2. 新增共享GameHeader，现有菜单、选角、竞拍、结算、排行、进度及只读回放均使用同一个品牌／导航／低强调版本行。右上角仅小字v0.5.2，不再显示“主菜单·版本”。真实来源只由返回操作表示。
3. 层房、构筑快捷入口、资金或选角步骤保留到独立上下文行，不挤占主导航；菜单进入进度时不造空上下文行、不显示虚假对局状态。
4. PC内容容器统一最大1440px、左右至少32px；页头、工具页标题、进度页签／成就、选角、结算与生存榜等共用同一宽度变量。PC规则在min-width:900px内覆盖，保留原窄屏规则，不宣称完成移动端适配。
5. 工具页共用标题／说明／右侧返回操作区，收紧顶部留白；菜单来源的排行／设置／规则明确“返回主菜单”。生存工具页从散落按钮改为同样标题骨架，积分／争夺子榜使用实际标题及原说明，不重复套两套标题；返回不提交、重算或推进对局。
6. 竞拍主工作区保留60vw抽屉安全内宽，并增加1200px上限；不为追求表面对齐把输入框扩展到双侧抽屉下面。抽屉顶部改用同一页头高度变量（PC76px，原窄屏86px）。嵌入的生存子榜使用父宽，不再重复套外壳边距。
