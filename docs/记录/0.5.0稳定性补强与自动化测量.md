## 1．只读交付自检

新增`npm run verify:offline`：只读取当前dist-offline，核对package／更新版本、固定与带版本HTML、头部构建标识、实际长度／SHA256、清单兼容字段、唯一校验行和生成说明；检查README与使用说明中唯一的“当前交付目录／固定入口”声明。允许历史releases文字留档，但不接受将其作为当前目录，也不回退到旧目录查找。

不写文件、不执行游戏、不构建或启动浏览器。读取后重新对照本次采样字节，发现构建中的交错修改就拒绝通过；清单已有validation只报告是否存在，不当成本次实际跑过门禁或实机通过。来源提交仅照实显示，不要求文档提交后HTML自动伪装为最新HEAD。

新增失败／只读规格覆盖错误文档目录、重复／缺失声明、旧固定入口、清单字段、头部身份、校验行、说明和CLI目录参数。同步将生成说明中的旧设置入口修正为进度→存档与备份。18项新增自检规格及原构建／文档定向共38项通过，类型／客户端lint和文档引用通过。源码版本仍0.5.0，未改游戏规则；按普通离线流程重建后再次运行只读自检。
