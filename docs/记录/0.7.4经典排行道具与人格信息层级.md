## 展示与实现

- 主表三列：排名、玩家与道具、最终积分。分数下方显示相邻记录的分差；第一项显示榜首，同分明确同分，不据此重新排序或重定名次。正分差小到当前精度会显示为0时写“距上一名不足0.01／0.0001分”，不伪称同分。两位／四位显示精度沿用偏好。
- 玩家姓名／角色、真人或AI标识及AI人格胶囊集中呈现。人格取实际aiProfiles.personalities；“均衡主义／合作主义／混乱主义”仍为流派，独立标明，不能当人格。资金和流派降为辅助行，仍可读取；缺少AI档案不能误标真人。
- 库存按每个实际ItemInstance展示，不去重、不合并、不截前几件；数量、顺序、重复份数全部保持。图标自动换行，库存多时允许增加行高；空库存明示0件／暂无道具。
- 复用原ItemIcon图集及回退策略，不新增贴图。图标按钮原生悬停标题包含名称／效果，鼠标／键盘／触控点击均可打开共享只读详情；门户内补齐图集CSS上下文，Escape／关闭／返回排行保留原焦点与滚动。仅一份共享弹窗，不为每个图标建立独立浮层。
- 抽出ClassicFinalRanking展示组件；GameResult保留左侧与外部导航。排行榜本地状态不写入存档、档案、回放或偏好，不修改引擎、难度、随机、计分、最终倍率、最终排序及同分裁定。
- 继续保留全20项、定位本人、完整行高亮与表头固定。取消玩家内容列横向固定，以便窄屏换行；仅tbody取消定位，thead三列仍全部固定，避免滚动时上一行内容穿过表头。
