## 二、数值口径

积分主值使用权威 `roomScoreSummaries.finalScore`。解释从原 `scoreBreakdowns.actions[].subtotal` 与本房倍率出发，箭头右侧为已经乘算的 `initialScore`；有追溯追加时单独说明，再与最终房间分区分。清零明确标注，不再把初始结果又乘一遍。显示精度可能四舍五入，因此采用“计分小计 × 本房倍率 → 该次积分”，不将舍入后的输入写成严格数学等式。单／双行动、基础／加算、清零和新心脏追溯仍可在明细查看。

资金净变化为原after.money−before.money，扣款来自各实际行动 `actualCost`，退款只汇总refund事件；余下差额明确为其他收入／支出，不冒充福袋返还。支出与收入按符号分别组织式子，零成本观望如实为0。例如实际合法福袋样本“扣款250−返还188＝净支出62”；双份、屏障退款、其他道具收支仍依原结果，不改费用。

没有改AI、RNG、引擎兼容标识、classic-tiered-1、schema8／catalogVersion7、v5文件、成长／角色条件、计分或发奖。恢复／重看不补发，版号只表明UI批次。
