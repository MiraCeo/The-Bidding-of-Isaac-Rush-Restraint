## 一、实现内容与口径

- 右栏改为“市场参考”：本局同层最近三个已结算房间从近到远排列；显示房间／人数、共同基准线、A／B独立高价名额边界。
- 高价边界来自原始公开高价名额，包含扰乱占位，不从最终发奖反推；保留完整数值，长显示采用近似格式并提供原值提示。
- 当前个人报价降为摘要：市场等价对照对应组最近历史高价线，计分等价／区间对照历史合作区。差值只是历史数值差，不表示胜率／推荐价／本房结果；硫磺火等仍明确为计分区间。
- 首房、换层、没有对应组行动／高价名额、全场观望分别如实显示，不用0补空、不取其他对局或跨层原始金额填充。
- “查看已结算回放”复用现有只读入口；返回时保留报价草稿与面板状态。理论能力上限和口径放入折叠说明，资金榜仍按原逻辑展示，不夹带改排行。

## 二、数据隔离与接线

`lib/ui/market-history.ts` 只接受当前session的公开结算，先排除其他层、本房和未来房，再去重／排序／截取三房，并复用原 `replayMarketModel` 的A／B名额口径；合作区半径使用该层公共基础资金，不用当前余额或角色本金。

经典从 `session.replay.rooms[].settlement` 提供来源，生存从 `game.roomRecords` 提供来源，父级按真实状态记忆化，编辑报价不反复扫描历史。传入右栏的轻量模型只含数值与缺值原因，不含奖励、玩家姓名、秘密turn或AI摘要。

`getQuotePreviews` 增加可选rules参数，默认行为保持；市场侧摘要沿用同一计算与计分区间，不重写费用／市场／计分公式。游戏引擎、AI、RNG、schema8／catalogVersion7、v5文件与成就／角色条件未改，不迁移或重算旧成果。
