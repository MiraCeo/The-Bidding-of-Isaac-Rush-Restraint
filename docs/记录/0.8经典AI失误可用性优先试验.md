# 0.8经典AI失误可用性优先试验

日期：2026-10-20。用户确认只试“先判断能犯什么错，再抽类型”。本轮只改[决策失误候选](./0.8经典AI决策失误扩展试验.md)的类型选择顺序，不改变25%／15%／5%／0%、强度、类型权重或合法性约束，不直接接入正式AI或重打0.8.0。

**结论：可用性优先确实提高奖励／预算类型的实际覆盖，约16%→28%，并消除新路径的无效类型回退；相对旧顺序的名次改善尚未清楚区分。保留为后续研究基线候选，不宣称难度平衡已完成，也未写入正式AI。**

## 一、唯一改动

旧顺序：触发失误→按45%／35%／20%请求奖励／预算／报价类型→无适用候选时回退报价。

新顺序：触发失误→确定本次轻微／中等程度→列出各类型合法、适用候选→只在非空类型之间按原权重归一化抽取→执行该类型候选。全部为空就保持原行动，不强行生成失误。

- 权重针对**类型**，不按各类型候选数量加权。例如只有预算与报价可用时，权重为35:20，不变成各50%，也不因预算候选多就再放大预算权重。
- 奖励／预算复用原生成器及原中等→轻微回退；报价使用原强制候选查询与原私有选择器，得到1个原规则的代表候选。报价候选计数0／1表示有无可执行代表，不冒充全部报价候选数量。
- 每AI有资金回合仍只判定1次随机失误机会；报价查询rate=1只作既有候选查询，不再增加随机触发机会。没有新抽样绕过概率或预算。
- 保留原80%轻微／20%中等请求比例，各类型金额范围、模型损失上限、现金／双行动约束、可见奖励差门槛、BOSS／末房限制均未改。
- 候选有效才抽类型，因此新路径没有“选了不可用类型再回退报价”；记录本次可用类型集合、候选存在性、实际类型以及全空未生效。请求／执行程度仍分别保留，不强制实际中等比例必须20%。
- 仅简单／标准采用新顺序，困难仍为旧报价型5%、最高原版0%；最高不枚举新候选、不创建附加随机流。

改变类型分布可能改变平均模型损失与实际修改率，但这不等于改大单类强度上限或25%／15%触发率。必须将这些指标分开报告。

## 二、配对试验与预登记

| 研究臂 | 概率 | 行为 |
| --- | ---: | --- |
| eligible25 | 25% | 可用性优先类型选择 |
| eligible15 | 15% | 同上 |
| prior25 | 25% | 上轮先抽类型／再回退的混合失误控制 |
| prior15 | 15% | 同上 |
| hard05 | 5% | 原报价型，作为共用困难 |
| highest | 0% | 完整原版，作为共用最高 |

控制是上一轮**混合失误版本**，不是更早的纯报价型，也不是正式classic-tiered-1低档。6臂都以完整原版为基础，不叠加规划衰减或预测额外噪声。

60个新种子块×5角色×3脚本×6臂＝5400局；每局15房、20人，每个脚本／臂300局。种子为`(0x08010000 + Math.imul(6001 + block, 104729)) >>> 0`，`block=0..59`，即通用公式6000..6059，不复用上轮5000..5059或更早各批。

角色isaac／lost／azazel／eden／jacob_esau，脚本pace／public-ai／explore不变。900组条件核对完整初始世界一致，后续各走真实决策与结算，不冻结奖励归属／后续现金，也不根据真人当前秘密报价改变候选。

主指标为pace／public-ai与5角色等权的正式终局名次，越小越容易；在种子块内先计算配对均值差。主比较预登记5组：eligible25－prior25、eligible15－prior15、eligible25－eligible15、eligible15－hard05、hard05－highest。

使用60个种子块、10000次bootstrap，5比较Bonferroni分配familywise alpha=0.05，各报99%区间。分脚本95%及explore仅作补充，不将各角色／回合当额外独立种子。不根据主矩阵结果继续调参数或选脚本。

## 三、实现与复现

新增独立适配器，不修改旧类型生成器／旧选择器；研究整局执行器复用已有可选transform。共享见证核验只补显式方案／混合类型臂和“可用集合全空时没有请求类型”的支持，默认旧批汇总结果保持相同。

单元测试检查类型权重归一化、非空可用集合必定选择其中之一、全空保持原行动、全部类型可用时与旧版本行动一致、输入不变、固定种子确定性、秘密报价隔离及困难／最高严格等价。旧5400报价、3600四档、5400混合失误的数据和汇总均只读复算验证，未覆盖旧run或回填来源。

在仓库`web`目录顺序运行：

```powershell
npx --no-install vitest run lib/ui/achievements/classic-feasible-mistake.test.ts scripts/classic-feasible-mistake-plan.test.mjs --maxWorkers=1
node scripts/run-classic-feasible-mistakes.mjs
node scripts/analyze-classic-feasible-mistakes.mjs work/0.8/classic-mistake-study/selection-<新目录>
```

研究默认跳过，只独占写新目录；run记录完整方案、Node／平台、HEAD／dirty与逐文件SHA256，收集前后核对未变。研究使用`research-only-feasible-first-lapse`身份，不生成正式存档、回放或成长凭据。

`quoteAnalysis`继续保留失误前模型，实际行动以before／after见证为准。本轮无浏览器实玩、真实存储操作、成就条件修改、升版、构建、commit／push、部署或发布。

## 四、5400局结果

数据目录`web/work/0.8/classic-mistake-study/selection-mcezLG/`。60种子块、5400局全部完成，900组条件的6臂完整初始世界一致；1539000个AI玩家回合的合法行动和实际扣款检查均未触发异常。收集前后来源哈希一致。

### 类型覆盖：这项改动本身有效

合并3脚本，只作机制诊断：

| 指标 | 新顺序25% | 旧顺序25% | 新顺序15% | 旧顺序15% |
| --- | ---: | ---: | ---: | ---: |
| 抽中失误次数 | 63196 | 63231 | 37645 | 37648 |
| 实际修改次数 | 45867 | 43053 | 27411 | 25759 |
| 奖励选择修改 | 5436 | 3125 | 3194 | 1844 |
| 预算过度投入修改 | 7511 | 3787 | 4555 | 2246 |
| 报价型修改 | 32920 | 36141 | 19662 | 21669 |
| 奖励＋预算／实际修改 | 28.23% | 16.05% | 28.27% | 15.88% |
| 无效类型请求后回退报价流程 | 0 | 43449 | 0 | 25703 |
| 抽中但未修改 | 17329 | 20178 | 10234 | 11889 |

新路径所有未修改回合均为3类候选集合全空；有至少1类候选时均执行了其中之一，没有强制选不可用类型。旧路径未枚举完整可用集合，不能把旧臂audit字段的0理解为“没有可用候选”。

新25%／新15%中，可用集合只有报价的回合为28962／17284，只有奖励为2472／1440，只有预算为2126／1322；3类型均可用496／314次。说明收益主要来自原来会抽到不可用类型的场景，而不是悄悄改变全部类型都可用时的选择公式。

实际修改／有资金回合，新顺序为18.239%／10.897%，对应旧顺序17.105%／10.236%。这不是将触发概率改成18%／11%或强制执行25%／15%，而是同一触发后更充分使用合法候选；仍有全空回合保持原行动。

### 预登记配对比较

“前者名次－后者名次”，负数表示前者更容易；60个种子块，5比较Bonferroni后的99%区间：

| 比较 | 平均名次差 | 99% bootstrap区间 |
| --- | ---: | --- |
| 新顺序25%－旧顺序25% | -0.305 | [-0.752, +0.168] |
| 新顺序15%－旧顺序15% | -0.138 | [-0.660, +0.405] |
| 新25%－新15% | -0.500 | [-1.020, +0.003] |
| 新15%－困难5% | -0.487 | [-1.053, +0.125] |
| 困难5%－最高0% | -0.040 | [-0.408, +0.337] |

各区间仍跨0；新简单／标准的上界接近0，但不能四舍五入成0或事后改用未校正95%宣称通过。相对旧顺序有均值改善，尚无清楚的独立降难度结论。

上轮某个边界有信号，不代表每批种子永久都能分开；本轮不是在同一批旧世界上观察“标准／困难变差”。不同批绝对均值不直接相减，效果只看本轮同种子控制。

### 资金与市场伴随观察

新25%／新15%的平均每次实际修改费用变化约+4.58／+4.94，旧控制为-0.78／-0.25；预算类实际多支付400095／233983，奖励换组的费用变化均0。当前类型分布更能体现过度投入，不再主要是报价少付。

BOSS前现金／层基础资金，新顺序20.17%／20.23%，旧顺序20.66%／20.63%；合作目标标准差／层基础资金分别约5.009%／4.947%与4.868%／4.816%。这些仅为伴随诊断，不单独证明资金或市场变化导致了名次效果，也不是剥离房间／跨局差异后的纯波动率。

## 五、采用状态与证据
