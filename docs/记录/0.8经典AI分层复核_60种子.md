# 0.8经典AI分层复核：60种子、3600局

日期：2026-10-20。承接[首轮研究](./0.8AI与成就平衡首轮研究.md)，按用户要求优先确定经典AI分层。**现行低3档参数不够支撑稳定的4级梯度；方案是最高原版不动，让低档能力差异贯穿估值、报价及预算。**具体定位／候选见[分层方案](../规划/0.8经典模式AI分层方案.md)，不是本轮直接上线新AI。

## 一、范围与方法

- 实际正式经典4档`classic-tiered-1`，没有混入生存档位；每局15房、20人。
- 60个新配对种子块×5角色×3固定真人槽位脚本×4档＝**3600局**。每个“脚本×档位”300局，独立种子块是60，不是300或3600。
- 角色为`isaac / lost / azazel / eden / jacob_esau`。脚本沿用原研究的`pace / public-ai / explore`，没有为本次结果修改打法；`public-ai`真人槽位始终使用完整原版，不随对手降档。
- 种子为`(0x08010000 + Math.imul(2001 + block, 104729)) >>> 0`，`block=0..59`；对应前轮公式的2000..2059，与前轮0、100..109、1000..1059不重合。
- 每个种子／角色／脚本的4档核对完整初始玩家、AI静态档案和全部经典地图的SHA256一致，共900组配对；后续道具归属和资金随真实决策分化，不冻结成相同过程。
- 使用真实`startClientGame`／`clientGameReducer`，复用旧研究控制器，不做成长／档案计算以降低开销；每房记录行动、费用、资格、实际发奖、资金和预测诊断。与旧完整成长研究的简单／最高2个条件逐房轨迹及终局哈希相等；另有最高／未分档原版对照和既有冻结回归保护。
- **1026000个AI玩家回合**逐个检查行动合法性、真实总费用不超现金，无触发异常。经典无淘汰后的AI续赛，不混用生存口径。
- 使用脚本不是模拟真人人群；没有浏览器、真实存储、下载导入或发布验收。成就本轮不发奖、不分析新阈值。

### 相邻档位的配对名次差

定义为“低档名次－高档名次”，**负数**表示低档使真人槽位更容易。每个种子先平均5角色，再对60个种子块做5000次确定性percentile bootstrap，以下为探索性95%区间，9组比较未做多重校正，不作确认性显著性结论。

## 三、行为诊断：有变化，但不等于有效分层

下表限定`public-ai`脚本下的AI，避免混合脚本：

| 档位 | 观望行动／AI玩家回合 | BOSS前现金／本层基础资金 | 目标预测绝对误差／本层基础资金 | 合作目标的标准差／本层基础资金 |
| --- | ---: | ---: | ---: | ---: |
| 简单 | 6.92% | 25.63% | 6.41% | 4.12% |
| 标准 | 5.97% | 23.63% | 4.90% | 4.44% |
| 困难 | 5.15% | 22.20% | 4.52% | 4.74% |
| 最高 | 4.96% | 21.66% | 4.56% | 4.88% |

- 观望随难度下降而上升，BOSS前也更保守地留下现金，说明当前档位确实影响了行动，不能说“按钮只是改名”。
- 预测误差并不在困难→最高继续下降；它是同一市场中各自行为共同作用后的误差，**不是对固定外部行情的预测准确率或因果证据**。
- 目标标准差在低档反而较小；该值合并各房、按层基础资金归一化，既包含房间位置也包含跨局差异，不是专门剥离过的“市场波动率”。没有证据把分层失败归因于“低档市场更乱”。
- `findings.json`另保留每层、每角色、现金耗尽、追加行动、实际获奖、资格、支出比例、报价限幅等；不挑一个好看的行为数代替终局体验。

## 四、源码核对与设计结论

现行`planning`只作用于主行为的局势／道具乘数指数；完整`analysis`仍传给A/B价值选择、报价中的奖励价值／机会预算和第二行动。预测误差则先改3种个人预测偏差，再经过报价混合、限幅和预算拟合，并不保证强度等比例下降。

因此本轮确定以下路线：

1. 保留简单／标准／困难／最高4个名称，定位分别为入门／常规／进阶／完整原版；默认最高继续不变。
2. 最高不加强、不削弱；不通过改资金、奖励、计分或秘密信息制造差距。
3. 低3档不再仅靠两个孤立参数，候选统一作用于主行为、价值选择、报价和第二行动预算；市场记忆也同步分层。
4. 先做隔离候选，再用独立校准／验收种子验证相邻档位；本轮不宣布候选α值已过关，也不直接改存档策略身份。
