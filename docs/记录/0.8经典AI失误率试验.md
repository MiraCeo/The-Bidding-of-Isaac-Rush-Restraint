# 0.8经典AI失误率试验

日期：2026-10-20。用户建议简单／标准增加失误几率并确认试验。本轮为**隔离报价失误试验**，不接入正式AI、不重打0.8.0，不把上一份[能力分层方案](../规划/0.8经典模式AI分层方案.md)的能力衰减同时叠加。

**结论：10%报价失误出现小幅降低难度的信号，但10%／3%尚不足以构成稳定的简单／标准梯度。本轮保留为研究候选，不替换正式档位，也不自动追加到现行低档。**

## 一、本轮到底试什么

| 试验臂 | 基础策略 | 额外触发率 | 失误程度 |
| --- | --- | ---: | --- |
| original | 完整原版，正式最高同算法 | 0% | 不追加失误 |
| mistake10 | 完整原版 | 10% | 80%请求轻微、20%请求中等 |
| mistake03 | 完整原版 | 3% | 只请求轻微 |
| current-easy | 现行简单 | 0% | 保留现有planning／forecastError，不追加 |
| current-standard | 现行标准 | 0% | 同上 |
| current-hard | 现行困难 | 0% | 同上 |

后3臂只是现行参照，不是把失误与现行弱化相加。最高与困难的正式行为不变。10%与3%的比较也包含失误程度分布差异，不能声称只隔离了概率这1个因素。

### 触发与实际生效分开

- 每名有资金的AI、每房只抽1次，双行动也只抽1次；自然观望仍可抽中，但没有可修改的报价就不生效。零资金不抽。
- 用整局种子、AI编号、房间位置派生独立随机流，判断触发／程度／候选；不消耗主决策或报价随机流。0%在创建附加随机流前返回。
- 保留原行为类型、A/B目标、行动数量、主义和人格；只改同一行动包中1份报价，不增删行动，不刻意让真人获奖。
- 不读取本房秘密报价或隐藏奖励真实ID。失误选择使用原决策已产生的公开预测及估值。

### 什么算报价失误

1. 轻微报价候选为原金额的0.85、0.90、1.10、1.15倍，中等为0.70、0.75、1.25、1.30倍，再取整数。重复金额或0金额不使用。
2. 按原版`candidateUtility`同公式，重新评估原报价与候选报价；只接受该份报价的预测效用确实下降的候选。轻微效用损失不超过0.15，中等不超过0.35。这是内部效用量纲，不是积分或胜率。
3. 每个候选同时通过真实行动规则、现金、原报价节奏上限和双行动总预算检查；不把非全押报价改成全押，不突破折扣后的实际总扣款。
4. 请求中等但没有合法有界候选时退到轻微；仍没有则保持原行动。触发率不等于实际修改率，也不承诺每次抽中都必须“犯错”。

本轮**没有试奖励选组失误／漏算构筑组合**。先只验证这个有界、可审计的报价机制，不能把本轮结果扩大到所有失误实现。模型效用下降也不保证实际少得分：预测可能不准，市场会受全体行动影响，双行动总体收益也不是两份单报价效用的简单相加。

## 二、样本与预登记

- 60个全新种子块×5角色×3固定脚本×6臂＝5400局，每局15房、20人；同种子／角色／脚本配对6臂。
- 使用`(0x08010000 + Math.imul(3001 + block, 104729)) >>> 0`、`block=0..59`，即前轮通用公式的3000..3059，与首轮及经典60种子复核不重合。
- 角色为isaac、lost、azazel、eden、jacob_esau；脚本仍为pace、public-ai、explore，算法与随机种子沿用既有控制器，不按试验结果更换打法。
- 主指标为正式终局名次，越小越好。pace／public-ai和5角色等权，在每个种子块先算均值差；主比较为10%－原版、3%－原版、10%－3%。
- 对60个配对种子块做10000次确定性bootstrap；3组主比较用Bonferroni分配0.05的familywise alpha，各报98.333%区间。探索脚本及分脚本95%区间仅作补充，不当作额外独立种子或确认性结论。
- 现行档位只作参照，不参与主比较的显著性挑选。没有基于本轮结果反复调整概率、金额范围或模型损失上限。

## 三、研究边界与复现

所有对局通过真实`startClientGame`与现有显式研究reducer执行，不使用浏览器／真实存储，不发成长奖励，不生成正式存档、回放或结算凭据。实验对象只存`research-only-quote-lapse`研究行和独立修改见证，不能称为新的classic-tiered-1对局。

`quoteAnalysis`保留失误前模型判断，实际改动见before／after行动包；不能把该字段作为修改后报价的完整生产解释。将来若接入正式AI，必须补齐解释数据、策略身份及存档／回放／成长核验，不是直接把研究wrapper拷进客户端。

在仓库`web`目录顺序执行：

```powershell
npx --no-install vitest run lib/ui/achievements/classic-mistake.test.ts scripts/analyze-classic-mistake-study.test.mjs --maxWorkers=1
node scripts/run-classic-mistake-study.mjs
node scripts/analyze-classic-mistake-study.mjs work/0.8/classic-mistake-study/trial-<新目录>
```

运行器分配新目录，独占写入run／rows／mistakes／complete／日志；默认普通测试跳过研究。run记录完整预登记方案、Node／平台、HEAD／dirty和逐文件SHA256，收集前后核对源码不变，不覆盖旧研究。

单元检查包括：原报价候选utility逐值相等、0%原版轨迹相等、6臂初始世界相等、固定种子确定性、秘密提交隔离、合法有界修改、双行动最多改1份、3%不请求中等，以及5400条件矩阵／计数／配对世界核验。

## 四、实际结果

有效数据：`web/work/0.8/classic-mistake-study/trial-yTbHPF/`，60个独立种子块、5400局全部完成，1539000个AI玩家回合的行动与实际总扣款检查均未触发异常。900组条件核对6臂初始完整世界相同；收集前后源码指纹一致。

### 正式终局名次

各格300局，越小表示真人槽位越容易：

| 对手 | pace | public-ai | explore |
| --- | ---: | ---: | ---: |
| 原版0% | 10.180 | 11.107 | 14.537 |
| 原版＋10%失误 | 9.603 | 10.763 | 14.430 |
| 原版＋3%失误 | 9.903 | 10.987 | 14.360 |
| 现行简单（参照） | 9.333 | 9.807 | 14.670 |
| 现行标准（参照） | 10.130 | 9.873 | 14.707 |
| 现行困难（参照） | 10.490 | 10.877 | 14.770 |

10%在两个主脚本都有改善；3%的改善较小。探索脚本中10%并不比3%更容易，不能说概率增加必然单调变弱。原版加失误也并非总比现行简单／标准更容易：例如public-ai面对现行简单9.807名，面对10%失误10.763名，因此**不能把10%这一数字直接替换现行简单档参数**。

### 预登记主比较

只平均pace／public-ai、5角色，种子块配对差为“前者名次－后者名次”；负数表示前者更容易：

| 比较 | 平均名次差 | 98.333% bootstrap区间 | 伴随观察：每局真人获奖份数差 |
| --- | ---: | --- | ---: |
| 10%－原版 | -0.460 | [-0.878, -0.023] | +0.120 |
| 3%－原版 | -0.198 | [-0.542, +0.140] | +0.097 |
| 10%－3% | -0.262 | [-0.622, +0.122] | +0.023 |

区间按3组名次比较做Bonferroni分配；获奖份数差只是描述性伴随指标，不共用名次的区间或显著性判断。

10%相对原版有小幅降低难度的信号，区间上界接近0；3%相对原版、10%相对3%均未清楚区分。不达到[分层方案](../规划/0.8经典模式AI分层方案.md)提出的相邻档位至少0.75名的实用目标，也没有完成独立候选验收或真人手感验证。不能把该结果写成“简单10%、标准3%已经平衡”。

### 触发不等于实际修改

以下合并3脚本，仅作机制诊断，分母为该臂AI有资金的玩家回合；重复世界下的回合不当作独立样本计算二项置信区间：

| 指标 | 10%组 | 3%组 |
| --- | ---: | ---: |
| 有资金AI回合 | 252254 | 252184 |
| 实际抽中 | 25919（10.275%） | 8081（3.204%） |
| 实际改动 | 16464（6.527%） | 5052（2.003%） |
| 抽中但保持原行动 | 9455 | 3029 |
| 最终轻微／中等修改 | 12873／3591 | 5052／0 |
| 每次修改的平均模型效用损失 | 0.0851 | 0.0661 |

部分抽中回合原本观望，或找不到同时满足“模型较差／合法／有界／预算内”的报价，因此未修改。不能为凑满10%／3%而强制生成不合理行动。

3脚本合并后的合作目标标准差／本层基础资金：原版4.717%、10%组4.698%、3%组4.724%，没有看到本口径下大幅增大离散程度。该值仍混合房间位置与跨局差异，不是专门剥离过的市场波动率；不据此声称已证明没有噪声影响。修改的平均实际费用变化为-7.60／-5.99，说明这个候选整体更偏向少付，而非对称扰动；这同样只是诊断，不能推导多付或少付必然让真人更容易。

## 五、采用结论与后续边界

1. **保留这个方向，不把当前10%／3%直接定为正式档位。**本轮验证了有界报价失误有一定作用，但相邻差距不足。
2. 不把当前研究wrapper叠加到现行低档后直接发布：本轮测的是“完整原版＋失误”，不是“现行planning／forecastError＋失误”，两者不能混称。
3. 下一候选优先检查实际修改率与失误类型，而不是只机械加大概率。奖励价值误判、组合遗漏、跨房预算失误仍未测试；若加入，需另做独立对照，不能沿用本轮效应数字。
4. 最高原版、默认选项、现行困难、生存AI、成就条件与0.8.0包全部保持原样；实验本身不注册新的正式策略身份。
