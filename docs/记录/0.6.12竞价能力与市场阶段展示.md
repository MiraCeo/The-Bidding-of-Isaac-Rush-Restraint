# 0.6.12：理论竞价能力与市场阶段展示

日期：2026-10-18。用户明确资金榜的等价数值指资金／道具推导的最大竞价能力，而非实际报价。本版落实只读能力展示，并把市场功能分为提交前个人影响、结算后公开分布，不引入预测模型或新玩法。

## 计算边界

- 排行仍按当前资金降序、原player ID决胜平手，不按理论上限重新排序。每行保留资金，另显示“竞／扰”单目标理论市场等价上限，不是其他玩家的本房行动。
- 竞拍名义上限是当前资金的整数部分；市场等价沿用现有完美视力叠加倍率。Steam折扣只影响实际扣款，不能借此超过原名义资金上限。扰乱受资金、现有比例及市场倍率约束，先取整名义上限再算市场等价。
- 双竞拍必须持有更多选择，两份正整数、名义总和不超过当前资金50%；双扰乱必须持有更多选择?，每笔受比例约束、实际总扣款不超过资金。持有双行动道具不等于可把两个单目标竞拍上限相加；双行动总额作为独立边界列入数值说明。资金不足以组成两份正整数时，不虚构可行双行动。
- 纯UI投影复用getRuntimeActionAmounts和validateTurn验证合法见证，不改engine、规则或保存结构，不读取玩家已选择的秘密行动；当前资金已包含本次入房的角色／道具影响，不再重复应用资金特性。
- 紧凑文本最多四位小数，发生舍入时加“≈”，悬停保留完整原值与双行动说明；只是展示格式，不降低计算或保存精度。格式器复用，排行能力投影按公开状态引用缓存，报价编辑不需要重算不变的资金排序。

## 市场分阶段

**提交前**：原高竖图改成“我的市场影响”，只接收真人、自己的草稿、规则及自己的理论上限。当前模式的单目标上限与A／B当前市场等价分开显示，条形只表示相对于本人单目标能力，不是获奖概率或竞争排名。双行动各自形成样本；观望及零资金不生成虚假零元样本。明确市场等价不等于计分等价，不显示未公开行动、合作基准线或预测积分。原RoomPrototype中的pendingRoomTurns市场投影已移除。

**结算后**：RoomResult新增默认折叠的“本房共同市场”，复用ReplayMarket只读视图，展开时才构建图表。只传已存在的settlement投影，不伪造回放元数据或重算结算；市场实心点、合作判定空心点及连接、高价边界／合作区遵循原图例。不是把合作区直接当作市场报价的获奖区。查看不提交、不推进、不补发成就；全场观望沿用无基准线说明。结算页其余结构本批不重做，逐点点击等额外交互不属于本批完成范围。
