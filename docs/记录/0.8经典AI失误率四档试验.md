# 0.8经典AI失误率四档试验：25%／15%／5%／0%

日期：2026-10-20。用户指定简单25%、标准15%、困难5%、最高0%，本轮按这组数进行独立试验，不直接替换正式AI。承接[10%／3%首轮试验](./0.8经典AI失误率试验.md)，首轮方案、数据与结论保留，不回写成新概率。

**结论：主指标均值顺序为简单＜标准＜困难＜最高，但3组相邻差距尚未清楚区分，尤其困难5%与最高0%接近。本轮按用户配置完成试验并保留候选，不能写成“4档已经稳定分层”。正式AI与0.8.0包未改。**

## 一、固定条件，只比较概率

| 研究档位 | 基础策略 | 额外失误触发率 | 失误强度 |
| --- | --- | ---: | --- |
| 简单 easy25 | 完整原版 | 25% | 80%轻微／20%中等 |
| 标准 standard15 | 完整原版 | 15% | 同上 |
| 困难 hard05 | 完整原版 | 5% | 同上 |
| 最高 highest | 原版正式最高算法 | 0% | 不追加失误 |

不同于首轮简单／标准程度分布不同，本轮3个非零档位的强度相同，隔离概率因素；这不是声称正式游戏的现行档位已经使用上述数值。不叠加现行低档planning／forecastError，也不叠加[能力分层方案](../规划/0.8经典模式AI分层方案.md)的新能力衰减。

沿用首轮有界报价失误实现：每名有资金AI每房抽1次，双行动不加抽；只修改1份合法、预算内且单报价预测效用较低的候选，保留行为类型／A、B目标／行动数量。轻微金额比例为0.85／0.90／1.10／1.15，中等为0.70／0.75／1.25／1.30；模型损失上限仍为0.15／0.35，无合适候选就保持原行动。

“25%”等均为有资金回合的**抽中概率**，不强制凑满实际修改率。原本观望或没有合适候选也可能抽中，但不乱生成行动；零资金不抽，独立派生随机流不消耗原决策／报价随机流，最高0%保持原版路径。

本轮仍只测报价型失误，没有测奖励选组、漏算构筑组合或跨房预算模型误判；预测效用较低不等于实际整局一定更弱，结论以真实结算后的名次为准。

## 二、预登记矩阵与分析

- 60个全新种子块×5角色×3脚本×4研究档位＝3600局；每个脚本×档位300局，每局15房、20人。
- 种子为`(0x08010000 + Math.imul(4001 + block, 104729)) >>> 0`，`block=0..59`，对应通用公式4000..4059，与先前0、100..109、1000..1059、2000..2059、3000..3059不重合。
- 角色isaac／lost／azazel／eden／jacob_esau；脚本pace／public-ai／explore沿用，不为本轮结果改打法。
- 同种子／角色／脚本的4档核对完整初始世界；之后各按真实行动／结算分化，不冻结奖励归属或后续资金。
- 主指标是正式终局名次，越小越容易。pace／public-ai和5角色等权，在种子块内先求平均配对差；3个主比较固定为简单－标准、标准－困难、困难－最高。
- 60个独立种子块重采样10000次，3组主比较以Bonferroni分配familywise alpha=0.05，各报98.333%bootstrap区间。分脚本95%区间和explore仅作补充；回合数、角色数不当作额外独立种子。
- 同时记录实际修改率、轻微／中等分布、资格／实际发奖、BOSS前现金和合作目标离散程度；不只凭失误次数判断档位已平衡，不按结果继续追调本轮概率或强度。

## 四、3600局结果

有效目录`web/work/0.8/classic-mistake-study/tiers-hi8Yy4/`，60个独立种子块、3600局全部完成。900组条件的4档初始完整世界相同；1026000个AI玩家回合的行动合法性及实际总扣款检查均未触发异常，收集前后来源哈希一致。

### 预登记相邻配对比较

“前者名次－后者名次”，负数表示低档更容易；只使用两个主脚本和5角色的种子块平均，3比较Bonferroni区间：

| 比较 | 平均名次差 | 98.333% bootstrap区间 |
| --- | ---: | --- |
| 简单25%－标准15% | -0.288 | [-0.713, +0.125] |
| 标准15%－困难5% | -0.183 | [-0.557, +0.197] |
| 困难5%－最高0% | -0.027 | [-0.340, +0.273] |

3个区间均跨0；这不是证明各档完全一样，而是本批没有清楚区分相邻难度。均值差也小于此前[分层方案](../规划/0.8经典模式AI分层方案.md)提出的0.75名实用目标，未达到完整分层验收。

不能把本轮25%与首轮10%的跨批均值直接相减评价加概率的收益：两批种子不同，首轮标准失误强度分布也不同。本轮结论以本轮同种子配对为准。
