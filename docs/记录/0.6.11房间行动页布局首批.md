# 0.6.11：房间行动页布局首批

日期：2026-10-18。用户授权借助内置浏览器逐步改造局内界面。首批只整理经典／生存行动阶段，不提前重做结算／终局，不修改规则、道具、角色、AI、RNG、成就条件或存档格式。

## 结构调整

- 资金排行与共同市场不再固定覆盖页面。开关移到房间HUD，同栏显示自己的资金名次；保留原展开偏好、局内切换和辅助阅读状态，关闭面板hidden／inert。普通PC使用220px排行、可收缩主体、240px市场的按需网格；窗口≤1100px时辅助面板移到行动区之后，不挤成窄报价列。只影响行动页，公共工具页／选角／结算不套用此布局。
- 奖励、报价与四种预览合为一个目标单元，移除海报光晕和大块空白。图标64px、完整名称／效果／属性、未知奖励不揭示的边界保持；支持subgrid时两组共享奖励／输入／预览三行，长文自然扩展，不靠裁切固定高度强塞。
- 模式、选择目标、单／双行动、输入focus选中、滑杆／数值联动、独立报价记忆、上限及观望二次确认逻辑保持。重复的“已选择此目标”等辅助句降为屏幕阅读器文本，原生radio／checkbox仍可操作。
- 确认区改为文档流，不再粘在视口底部遮住输入；实际扣款与错误提示保留，观望与确认位于同一操作行。行动阶段的生存条、入房提示、标题与模式间距收紧，不改结算阶段样式。经典返回主菜单移到标题操作区，行为不变。

## 浏览器逐步核对

独立来源为`http://127.0.0.1:41867/`（生存）和`http://localhost:41867/`（经典），不是用户原来源。正常UI开局，不注入内部状态，不清理旧数据。开发服务器仅监听loopback。独立输出`web/work/v0611-room-layout/`保留修改前、三轮迭代与验收截图；开发预览与最终离线构建的证据分别说明。

- 修改前复现固定侧栏遮挡与报价输入落到奖励海报下方。迭代过程中实际读DOM矩形而非仅凭CSS判断：收紧后1280×720 CSS视口的生存普通首房，两侧展开时A／B数值输入顶端均约505.91px，确认区底端约716.68px，未覆盖输入。此数字只对应该样本，长入房效果、成就通知、多行文案、其他窗口与缩放不得直接沿用。
- 生存以撒标准首房：竞拍A改37，打开设置再返回仍保留37和当房展开状态；切扰乱A=19，四数值分别为19／19／47.5／23.75；观望只改变草稿，恢复扰乱仍19；主动确认后真实扣款19、资金1100→1081、进入原结算，再正常进入第二房。第二房宝箱奖励继续显示“未知道具”，未提前揭示。独立测试档自然获得两败俱伤铜章，不属于新增玩法或用户原档授权；未完成整局。
- 经典测试来源通过原设置入口手动开放角色，仅作本来源的测试准备，不补发成就。正常选择雅阁和以扫，A=19／B=21可同时选择，预览分别正确，汇总扣款40，共享60名义上限仍有效；未因此修改角色权限或引入跳过门禁的测试入口。
- 真实0资金、更多修正组合和范围上限由既有组件回归覆盖，不冒称本轮都做过浏览器实操。此轮为HTTP页面核对，不代表直接file、文件往返、完整长局或全部PC尺寸验收。
