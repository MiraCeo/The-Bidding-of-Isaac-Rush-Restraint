# 0.8现行成就平衡观察表

日期：2026-10-20。当前0.8.0／117枚／schema8／catalog7的离线脚本观察，不是已批准的阈值调整表。完整方法与结论见[首轮研究](./0.8AI与成就平衡首轮研究.md)，现行条件以[成就总表](../规划/成就总表.md)为准。

## 读表口径

- 主矩阵1200局＝10个配对种子块×5角色×8模式档位×3脚本；“单局命中”过滤模式／角色／档位硬门槛，但没有把道具持有机会全部过滤，不是真人概率。
- 新档18条路径×20局，只包括经典最高和生存标准，角色按真实解锁轮换。角色限定项只统计路径中实际使用过该角色者，未解锁是另外的机会限制。
- 首获中位局数只取已命中者，没命中显示截尾，不填0；不同等级命中人群不同，中位数不能用来推断金先于银。
- 金额、次数、房间数、层数与对局数不可混用；目标单位取现行总表。累计项目单局0命中不代表难度异常；各显神通不计算单局率。
- 默认标准生存的新档路径不具备最高难度金章资格，表中“不适用”不等于0次失败。
- 原始数据位于`web/work/0.8/balance-study/analysis-1wUzcR/findings.json`，运行与见证均为研究JSON，不是浏览器玩家档案写入验收。
