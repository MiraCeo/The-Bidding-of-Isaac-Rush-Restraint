- 两模式独立卡片：现有像素角色、模式、状态、实际难度、个人进度与续玩／结果入口。空模式不假造角色或分数；进行中显示真实已结算房间／道具数；经典终局沿用原最终顺序与积分，生存沿用原记录名次和累计分。
- 提前淘汰时明确个人淘汰层与冻结事实，AI续赛不会把个人展示切成后续层的成绩。进行中生存进度条只描述本层，不预设一定30房或其他固定终局长度。

- 总览快捷入口进入记录、统计、存档管理，原筛选状态仍由ProgressCenter维护；原继续／结果回调保持，不写新档案模块、不改变统计公式或保存格式。
