# 0.5.5成就分组、金属徽章与达成回显

日期：2026-10-15。依据用户提供的两张实际截图反馈，只处理成就浏览分区、等级辨识和获得成就的回显，不增加玩法或成就。本批作为PC展示补丁0.5.5，继续36枚／六分类及21铜／11银／4金，隐藏名单A03／C07／F02不变。

## 一、全部视图按分类独立起行

- 以A～F固定分类顺序分为六个真正的section，各自有标题、分类编号、分割线、该分类已达成／完整数量及当前筛选命中项数。每类独立grid，不把下一类的卡片填入上一类最后一行。
- 分类、状态、等级、名称／编号搜索仍可组合；无命中的分类不生成空标题，全无结果保持原清除筛选入口。
- 自动／1／2／3列继续基于原容器宽度，每类统一应用当前列数。总览和分类完成分母仍取完整档案与目录，不受筛选影响。
- 最近达成／进度排序改为分类内排序，界面明确提示，保持分类分段完整；纯选择器仍按所选方式排序，分组函数只稳定分桶，不重算进度、不跨组混排。
- 详情弹窗、关闭返回焦点、角色前置入口及隐藏名称／排序不泄露保持。

## 二、左侧徽章明确表达等级

- 未达成也分别采用暗铜、冷银、深金的金属色边框／图标／底面，不再全为同一棕色。达成后提高对应金属亮度与表面高光，卡片边框／背景也使用对应等级色，而非一律金色。
- 左侧徽章新增“铜／银／金”铭牌与1／2／3颗装饰点，保留原专属代码图标及分类轮廓。装饰点仅表示静态等级，不是I／II／III累计阶梯，也不增加徽章或领奖状态。
- 隐藏未达成项只显示统一问号图标，等级仍可辨认；详情允许查看真实图标／条件，已达成后恢复展示。
- 保留卡片文字等级以辅助辨认，不只靠颜色。进度条统一为等级色细条，不依赖浏览器默认绿色样式。

## 三、两模式统一成就达成通知

原位于整页底部的“成就已保存：名称列表”替换为右上方紧凑通知：

- 标题“成就达成”、新徽章数量、已保存标识；每项独立展示已达成专属徽章、名称、等级及收藏札记。
- 右上固定定位，不占正文流、不把游戏页面向下撑长、不主动滚动页面；没有遮罩或模态焦点捕获。长批次在限定高度内滚动，保留全部条目，不截断丢弃。
- 手动“知道了”关闭，不自动计时消失，不增加音效。通过语义output礼貌播报已保存的名称与等级；现有减少动画偏好和系统prefers-reduced-motion均禁用轻微入场动效。
- 经典与生存共用`AchievementNotice`；仅接收原协调写入返回的真正newlyAchieved，按已知目录ID生成展示，不解析拼接后的文字来反推成就。
- 同局未读批次合并去重，空结果不重弹；明确关闭后只有新的达成结果才再提示，普通重载不读历史补弹。新局／恢复代次改变不显示旧局批次。
- 明确替换档案清除旧提示；新增临时反馈代次守卫，替换后才返回的旧结果不得重新弹出。此守卫只管显示，不参与receipt、计数或事务判断。
