# 0.7.7：对局记录来源分层与列表前置

日期：2026-10-19。接续[总览首批](./0.7.7进度总览美化与真实摘要.md)，按用户请求继续对局记录美化重排。保持0.7.7，只改记录页与其共享回放展示，不重排统计、存档与备份、成就或历史市场，不push。

## 信息与展示

- 保留本局／最近／临时文件回放的原入口和回调，压缩其卡片留白、状态与操作分组。列表前新增“完整回放／完成结果”来源切换，不按近似ID合并两套数据。
- 完整回放使用原IndexedDB索引；完成结果使用档案实际保留历史。前者支持原查看／导出／删除，后者只展示结果，不伪造可回放按钮；历史最多200条与累计统计的区别继续可见。
- 两来源共用角色、真实难度、完成状态筛选；角色图像沿用现有素材，成绩、名次和存活／淘汰状态分主次。进行中片段没有终局名次／分数时仍显示未知，原版未分档不重标为新档位。
- 模式、来源及筛选作为临时进度导航状态保持，查看回放或进入总览后返回不丢分类；没有新增存档字段、统计数据或持久化协议。结果来源选中时卸载回放库面板，清理其待读取／预览状态，不让隐藏面板拦截Esc。
- 入库、导入、等价核对、整库备份及技术说明统一放在列表后的“回放管理与备份”折叠区；原预览、确认／取消、异常反馈和删除确认保留。库容量标注“全库”，明确两模式共用，不与当前模式的筛选条数混淆。
- 黄棕面板、紧凑操作、角色／状态胶囊与前批总览衔接。主要列表先于维护工具，表头固定、表区可键盘聚焦与横向滚动；不删除未显示在窄屏首段的列。

## 代码与数据边界

`CompletionHistoryPanel`负责原档案结果的模式／筛选展示；`RecordFilters`统一两来源控件。`ReplayLibraryPanel`增加可选records展示和受控筛选，原默认展示继续可用；工作、读取、校验、取消、导出及删除方法逐字核对保持。

原回放库底层、备份恢复面板、DataManagement、SurvivalDataManagement、统计／档案管理、总览组件与只读模型源码均与首批一致；ProgressCenter的总览、文件和统计JSX分支逐字核对一致。只扩充临时ProgressSelection的来源选择，不改AI、随机、引擎、完成登记、文件格式或任何保存事实。
