## 重点人工检阅项

1. 道具优先：猫尾巴的落空／复制、骰子的翻倍／清零、幸运脚的名额、屏障退款、穷人护符与Steam大促各写各的，不只统一加“地下室”。
2. 角色优先：游魂的不安、雅阁和以扫的双份忙碌、以撒／纸上角色名的替换；不把所有角色都适用的条件改写成角色限定。
3. 普通竞拍A／B两类本轮全部沿用，不为凑原作梗重写整张表。
4. 已修正的语义边界保留：跨局角色不写成同局切换；最低存活不写“只差1分”；雅阁不等额报价只保证至少一组实际获奖；扰乱空位不写成全部奖品无人领取。
5. 短句中的道具拟人和场景是氛围；实际计分、奖励、退款与随机仍完全按本作现行规则，不把原作道具效果搬来当成本作条件。
