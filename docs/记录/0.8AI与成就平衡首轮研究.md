# 0.8 AI与成就平衡：首轮研究

日期：2026-10-20。用户要求测试AI和成就平衡。本轮已按[预注册方案](../开发/0.8AI与成就平衡测试方案.md)完成**1680局离线研究**，截止于证据与调整建议；没有修改AI参数、成就条件／阈值／等级／角色前置或0.8.0交付HTML。

## 一、先给结论

1. **AI基础合法性没有发现异常**：所有研究局正式结束，逐AI回合核对行动合法性和实际现金预算；主矩阵真人参与期337715个AI玩家回合、真人淘汰后58420个AI玩家回合，违规计数0。
2. **生存简单／标准分层比较清楚，困难／最高相近**；经典简单对公开信息强脚本明显更宽松，但标准／困难／最高在部分打法下区分较小。不能用单局不单调就认定失效。
3. **优先复核背水一战III和厚积薄发III的金阶节奏**：18条新档路径分别17条和16条在20局内命中，已命中者首获中位为5局和8局。只是候选，不直接提高门槛。
4. **吊车尾III自然积累慢**：9条标准生存路径20局内0条命中，最终累计1～7次；不是已证明不可达。应补长路径和有意识的压线打法，而不是马上下调。
5. **不恢复旧“孤注一掷93.1%过易”的结论**：当前50%实扣规则下，主矩阵各条件单局命中2%～54%，与脚本／模式有关；20局内大多获得也符合首次体验铜章。
6. **资金类明显偏向生存积累**：本次精打细算III经典路径0/9、生存路径9/9；不能把模式资金尺度和真人房间数的差异直接变成统一加量理由。
7. **联合实际观察到116/117枚**：固定角色10局档案观察109枚，正常解锁轮换20局档案观察113枚；联合唯一未命中为F05吊车尾III。这个覆盖数不等于全部边界验收，也不把未命中直接判为不可达。

### 1. 背水一战：当前更值得优先复核的金阶节奏

背水一战III现为10次全额正常报价并实际获奖，17/18条新档20局内获得，已命中者中位第5局。对360局原始成长见证再按生产事件编码只读解码：570个全押获奖事件中476个（83.5%）不满足孤注一掷的50%本层角色初始资金实扣门槛，其余94个满足，缺失本金证据0；每局事件数与生产进度D09逐项一致。
这验证的是两项既有规则不同，不是规则错误；也不能把所有476个事件都说成“低余额刷取”，因为折扣同样会降低实扣，见证不足以仅凭扣款推断名义余额。主矩阵对应1834个全押获奖事件中1396个低于该实扣门槛，规律相似。
建议下一轮先讨论背水银金的累计节奏，不急着把孤注扩成另一个全押次数系列；本轮不加50%条件，也不直接改1／5／10。派生脚本与结果在准备目录`derive-all-in.cjs`／`derived-all-in.json`，旧见证不修改。

### 2. 厚积薄发：保留铜级前置，银金列为延长节奏候选

当前1／5／15，金阶16/18条命中，中位第8局；主矩阵120条固定角色10局路径有63条获得金阶。数据支持优先复核长期收藏定位，但还需要先明确期望窗口。旧1／10／30仍只是讨论输入，不算本次批准；铜级及阿撒泻勒前置不提高，不改BOSS生成或奖励规则。

### 3. 吊车尾：稀少的是机会，不只是一串阈值

标准生存新档20局共713个人类参与层结算、584次实际通过，其中最低存活34次；9条路径最终累计1～7次，银阶4/9，金阶0/9。主矩阵600局生存共1763次通过、最低存活100次；最低存活不是“只差1分”，更强打法也未必更容易积累。
优先补30～50局路径与主动控制生存边缘的脚本，区分长线收藏、角色／道具暴露、并列机会与操作目标，再决定是否调整1／5／10。当前没有证据将其写成不可达或马上降金阶。

### 4. 金额类与角色解锁：模式影响必须单列

精打细算III的5000目标在经典新档0/9、生存9/9；钱生钱III为经典0/9、生存7/9，聚沙成塔III为经典0/9、生存4/9。这些是不同房间数、后期本钱与道具暴露共同作用，不等于生存应该被统一削进度。
本次经典每路径固定300个真人房间；标准生存每路径240～490个。跨模式共享成就应先确认是否接受不同自然积累速度，再讨论金额；不在本轮引入折算、模式拆分或第二套领取规则。
实际解锁路径（18条）：游魂15/18，已解锁者中位第9局；阿撒泻勒18/18、中位第6局；伊甸15/18、中位第4局；雅阁和以扫16/18、中位第3.5局。剩余分别3／0／3／2条在20局截尾。固定角色研究不拿来冒充这些正常解锁路径。

### 5. 保留项

孤注一掷当前三种脚本／两模式各档的单局命中2%～54%，20局17/18获得且中位第5局，符合“有本金门槛的首次体验”这一定位，不能继续用旧0.6.5的93.1%作为现行证据。
两败俱伤主矩阵1200/1200单局命中，属于环境体验铜章；全军覆没在各格15/50～44/50命中，仍是较常见环境银章。新档18/18均第1局获得两项，只对应这3个新档种子块，不是所有新玩家必得的概率结论。没有因此重开已裁定的等级／隐藏或将它们改成主动扰乱要求。
尾巴复制／消除、神秘礼物、我全都要等长线在20局仍有明显截尾，先不统一降阈值；不把原作／角色初始装备当作房间获得型奖励补数。
