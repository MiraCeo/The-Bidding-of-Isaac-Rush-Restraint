## 一、札记修改

`collection-notes.ts`改为按稳定存储ID显式列出各阶段短句，移除按目标数值生成模板的运行时拼接。正式编号由既有`numbering.ts`映射，不把两套同形编号混用。

### 46条模板重写

范围为首轮审查列出的22个系列：失败／恢复、合作／落选、扰乱／退款、骰子／低资金／幸运脚、全押获奖、资金节省／窃取、隐藏礼物、双行动及生存阶段。银金不再只替换数字，也不再用“次经历”混写行动、组、房、层的区别。目标条件仍由原目录与判定器负责，札记仅提供对应经历的短文。

### 5条语义修订

| 正式编号 | 成就 | 处理 |
| --- | --- | --- |
| B23 | 两败俱伤 | 落在本次已发生的路径轮空，不写“总有”这类必然规律 |
| C15 | 两处空席 | 描述A、B均出现空位，不限定恰好2个空缺或所有奖品无人领取 |
| C17 | 竹篮打水一场空III | 调侃反复收到空奖励，不再替随机触发赋予玩家“不肯空手离开”的意图 |
| E10 | 各显神通 | 不再写“同一场竞合”，避免暗示单局使用5名角色 |
| F15 | 险中求胜 | 明确最低存活成绩到冠军的经历，不暗示紧贴斩杀线或仅差1分 |

保留“母亲已经来了，成功呢？”“请签收这份本来属于你的空气。”“战术没有问题，骰子另有想法。”等既有辨识度较高的短句。文学修辞不机械替换为数字；精确条件计数仍使用上一批统一的阿拉伯数字。
