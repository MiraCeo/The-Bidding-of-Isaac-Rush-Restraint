# 0.6.5现行成就模拟与难度建议

日期：2026-10-17。用户授权实施研究，**截止到列出调整建议**。本批不改117枚成就阈值、等级、隐藏、角色门槛或玩法，不做实机验收、push、部署；应用仍0.6.5，不为研究报告另打离线包。

## 一、方法与边界

使用当前正式经典／生存规则、完整五角色、三种脚本人类槽策略（均摊报价、公开信息AI、探索扰乱）。保留原研究策略与随机流，不注入道具、不更改AI强度、抽取、积分或奖励。真实正式结算原因进入当前schema7／catalogVersion6的生产档案求值；旧难度报告与旧目录汇总不混入本次结果。

现有研究的单局控制器仅增加可选只读观察回调；无观察时行为不变，有观察时动作、终局和成长指纹须与原控制器精确相同。隐藏道具只在结算后分析机会，绝不用于行动决策。

### 三组研究

| 组别 | 设计 | 数量 |
| --- | --- | --- |
| pilot | 2种子×5角色×经典／四档生存×3策略 | 150局 |
| main | 20种子×同一75格条件矩阵 | 1500局 |
| campaign | 5独立种子块×3策略×经典／标准生存×20局，新档只轮换真实已解锁角色 | 600局／30条连续路径 |

固定配对种子公式`(0x65100000 + (index+1)*7919) >>> 0`：pilot索引0～1，main为2～21，campaign为1000～1099，三组互不重用。相同种子在不同角色／策略／难度条件间配对，不当作1500个独立真人样本。

main每个条件还保留一份真实生产API处理的20局内存档案，共75条固定角色累计路径。控制角色的矩阵是实验条件，不受新玩家UI选角锁限制，不代表新档已经能用游魂；另用campaign的30条路径补足正常角色解锁与轮换。连续档案只继承成长记录，每局道具／资金仍按正式开局重置。

### 指标

- 全117枚：单局达成率、分角色／模式／难度／策略的计数与区间；连续档案第5／10／20局进度、首次达成局数和未达成截尾。
- 新五系列：真实原因房数、持有房数、实际触发机会和取得道具数量。尾巴机会排除奖励自身是尾巴的情况，并记录单／双组机会；永恒六面骰使用实时正积分证据；获得型只计实际房间发放，不含初始装备。
- 固定角色和可用角色轮换路径分别报告，独立角色前置与首次解锁保留。非适用模式不当失败，零触发不当不可达，未达到的局数不填0。
- 同一系列不拿铜银金的天然包含关系当重复设计证据；交叉重叠先以57个卡片代表项考察，只作脚本样本的描述性关联，不推断逻辑等价或真实玩家行为。

区间仅用于固定条件内20个脚本种子的单局模型诊断，不代表真人概率。持有／机会房间具有相关性，不给伪独立的房间置信区间；自适应角色轮换路径也不输出伪精确的独立伯努利区间。首次达成中位数如有，仅为**已命中路径中的观察值**，截尾单列，不能冒充总体耗时。

## 二、可复验输出

在`web`目录使用：

```powershell
npm run report:achievements:current -- pilot
npm run report:achievements:current -- main
npm run report:achievements:current -- campaign
node scripts/analyze-current-achievement-study.mjs <pilot绝对目录> <main绝对目录> <campaign绝对目录>
```

每次分配新的`web/work/current-achievement-study/<类型>-随机串/`，结果排他写入，不允许覆盖或路径越界。main和campaign各分4批，保存批次行、最终档案、每局完整权威成长上下文／原因见证、摘要、来源哈希、日志和状态。只有三组都完成、来源相同、种子不重叠，才生成分析。

分析重新核对全部2250局的上下文指纹、根身份、机会记录，以及各组最终档案哈希；汇总来源与原始样本可逐项关联。记录源码提交和源码文件哈希，不把后续文档提交冒称测量来源。

准备期输出在`web/work/v065-current-study-preparation/`。原难度研究、0.6.5扩展证据与dist-offline全文件事先留大小／SHA-256清单；研究结束再核对保持。默认完整测试不运行重研究，既有概率报告不重新写入。
