# 0.6.5现行成就模拟与难度建议

日期：2026-10-17。用户授权实施研究，**截止到列出调整建议**。本批不改117枚成就阈值、等级、隐藏、角色门槛或玩法，不做实机验收、push、部署；应用仍0.6.5，不为研究报告另打离线包。

## 一、方法与边界

使用当前正式经典／生存规则、完整五角色、三种脚本人类槽策略（均摊报价、公开信息AI、探索扰乱）。保留原研究策略与随机流，不注入道具、不更改AI强度、抽取、积分或奖励。真实正式结算原因进入当前schema7／catalogVersion6的生产档案求值；旧难度报告与旧目录汇总不混入本次结果。

现有研究的单局控制器仅增加可选只读观察回调；无观察时行为不变，有观察时动作、终局和成长指纹须与原控制器精确相同。隐藏道具只在结算后分析机会，绝不用于行动决策。

### 指标

- 全117枚：单局达成率、分角色／模式／难度／策略的计数与区间；连续档案第5／10／20局进度、首次达成局数和未达成截尾。
- 新五系列：真实原因房数、持有房数、实际触发机会和取得道具数量。尾巴机会排除奖励自身是尾巴的情况，并记录单／双组机会；永恒六面骰使用实时正积分证据；获得型只计实际房间发放，不含初始装备。
- 固定角色和可用角色轮换路径分别报告，独立角色前置与首次解锁保留。非适用模式不当失败，零触发不当不可达，未达到的局数不填0。
- 同一系列不拿铜银金的天然包含关系当重复设计证据；交叉重叠先以57个卡片代表项考察，只作脚本样本的描述性关联，不推断逻辑等价或真实玩家行为。

区间仅用于固定条件内20个脚本种子的单局模型诊断，不代表真人概率。持有／机会房间具有相关性，不给伪独立的房间置信区间；自适应角色轮换路径也不输出伪精确的独立伯努利区间。首次达成中位数如有，仅为**已命中路径中的观察值**，截尾单列，不能冒充总体耗时。

### 优先复核的难度落差

1. **环境旁观型银／金明显偏易**。“两败俱伤”主矩阵1500／1500局，“全军覆没”882／1500局；三种脚本策略分别为500／500与276、305、301／500，不是只有主动扰乱策略才容易。经典／简单／标准／困难／最高的全军覆没分别153／232／182／164／151（各300局）。30条新档路径两项均在第1局达成。
2. **另辟蹊径金阶过短**。当前1／5／10，30／30条新档路径拿到金，命中者中位4局；经典15／15、中位5局，标准生存15／15、中位2局。它与“不谋而合”在主矩阵单局高度伴随：后者1396局、前者1379局，1379局同时出现。两者并非同义，前者是合作奖中的更窄子情形；但门槛反而短，成长辨识度不足。
3. **和而不同、厚积薄发偏快但可保留入门铜阶**。“和而不同”金阶30／30条、中位7局；“厚积薄发”金阶25／30条、中位8局（经典11／15、中位12局，标准14／15、中位6.5局）。不因此改铜阶或阿撒泻勒前置。
4. **过关斩将金阶更像存活经历而非高难挑战**。标准生存新档14／15条在20局内达成，中位1.5局；主矩阵单局309／1200、累计58／60条。1／3／5层是单局层数，不是累计局数，不能直接套成1／10／50。
5. **吊车尾金阶偏慢，证据还不足以下调**。新档标准生存0／15条在20局内完成10次；主矩阵60条生存路径仅1条在第19局完成。银阶新档8／15条、中位18局。更适合先补长路径及不同表现策略，不能把零命中当不可达。

### 重叠核对

- “薅羊毛”333局、“精打细算I”329局，后者329局均伴随前者：一个是首次减少扣款，一个是累计省100，事件意义不同，但100资金在部分局内较快。保留铜级反馈，先不合并。
- 经典“独占鳌头”和“败而不馁”在本样本均14局并全部伴随；不能证明冠军必定先失败，也不能以配对样本直接删除后者。建议后续比较整局连胜与逆转打法的区别。
- “两败俱伤”和生存完成／经典完成等高重叠主要来自环境事件几乎必遇，不能据此删除完成对局成就。银／金定位优先复核，比盲目去重更直接。
- 三级内部包含关系不算重复；跨卡片的条件包含、同局伴随、同一时刻达成分开解释，不把全局Jaccard当玩法因果。
