# 0.6.2：紧凑成就卡片与统一详情

日期：2026-10-16。用户确认上一轮方案后实施。本批只优化现有PC成就浏览与详情，不增加成长内容或修改玩法、判定、存储与权限。

## 一、卡片与列数

- 三级卡片使用“名称＋等级节点／具体条件／目标进度”三行；已获数不再作为可见文字重复一遍，等级节点用实心／空心区分，保留金属等级提示及辅助阅读说明。
- 尚未取得等级直接显示条件，部分已获显示“下一阶”；图标仍代表当前筛选范围内最高已获等级，进度仍对应匹配范围内的真实目标，不借铜级成果高亮金级。
- 卡片内边距12px、图标50px、图文间距10px、分类间距20px；正文不缩小、不截断关键条件。一次性独立成就、全部达成及待正式结算确认沿用原口径。
- 分类按钮继续显示筛选联动的卡片计数；分组保留字母、名称、换行和分割线，删除重复的已获计数。列表只显示“显示n项”，顶部107枚真实徽章总览保持，不再反复解释卡片／徽章内部计数。
- 使用内容容器宽度：不足620px一列、620px起两列、980px起三列、1480px起四列；自动或手动4列才在宽屏进入四列，手动1／2／3仍是对应上限，空间不足自动回落。沿用独立布局偏好v1键与旧偏好，不写玩家档案；五列不加入本批。
- 公共页面标题、导航、工具页HUD策略及其他页面宽度不改；不是同时重做整个站点。

## 二、统一详情

- 系列按整组成就展示，标题不再重复选中子级的I／II／III。原编号仍显示在标题和各级行中；选中子级高亮，各级原名保留在可访问名称与提示中。
- 一句共同触发行为＋三条紧凑等级行：金属／正式编号、目标、独立原始进度、状态与日期。不将不同子级的计数强行合并，也不从阈值反推已达成。
- 达成日期紧随对应等级，可展开完整时间；原ISO时间不改。未达成只显示一次状态，不再加“尚未达成”行。
- 模式放入标题标签，隐藏属性保留；没有角色关联就不显示“无·收藏挑战”。整个系列中任一级关联角色时均保留完整真实前置，不能因浏览银／金级丢掉铜级解锁说明。
- 判定细则默认折叠。只从原完整条件中抽取**第一次出现的该级阈值**为“目标值”，目标移到各级行；其余完整规则去重保留，包括第一句里的同父分支／实际发放，以及无关的第6名、伊甸前置3件等数字。独立成就完整条件仍保留，只合并已经包含的重复说明。
- 收藏札记集中为一个默认折叠区；系列按铜／银／金按钮切换，只展示所选子级真实达成后解锁的原文。未取得该级只显示一次“达成后解锁”，不保存浏览／解锁标记。显式回退档案立即重新锁定札记。
- 关闭按钮、返回列表、Escape、焦点返回、通用统计规则入口保留。条件与札记不从数据中删除，只改变展示层级。
