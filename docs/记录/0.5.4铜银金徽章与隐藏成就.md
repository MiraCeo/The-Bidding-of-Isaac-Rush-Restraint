## 三、历史数据裁定与本轮边界

用户接受“已有可靠累计事实可讨论继承，过去根本未记录的事实从启用后统计”的原则，现将后续新增累计等级按以下规则准备：

1. 只使用已经核验的权威账本，不扫描旧history、只读回放或导入旧对局补造未记录原因；不得按相似最终指标推断。
2. 若后续新增门槛复用已有可靠累计事实，可继承对应统计；首次新正式结算的成功事务中再判断新门槛，已超门槛者以该次成功入账时间作为新徽章达成时间，不伪造历史时间。
3. 过去没有记录的原因／次数需新事实和明确启用边界，只从启用后统计；不能将原成就布尔完成状态冒充完整累计次数。
4. 旧ID、原条件、达成时间及角色前置不得覆盖或重新映射为另一个奖励；重复恢复与失败重试仍只统计一次。
5. 0.5.3新增六项的不追溯边界原样保留，不因后续可继承某项可靠统计而放开旧结果追溯。

**本批没有新增累计门槛，故不需要执行上述新门槛激活迁移。**实际代码只是读取原36项已核验状态进行分级和隐藏展示，不写激活事件、不回填新达成时间，不构造一套无业务用途的迁移字段。引擎、v5、growth1、档案正文1、成长schema1／2／3及catalogVersion全部保持。等级／隐藏为静态配置，不写入玩家档案；原玩家档案正文不变，旧备份不改写。
