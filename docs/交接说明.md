### 不可直接照搬的假设

1. 已登记receipt会让现有完成函数提前返回，不能在其返回后随便加成就代码就假定旧局也处理过。区分统计登记／成长处理／规则启用与回溯。
2. 只读导入／回放库恢复不发奖；恢复档案是恢复已有记录，不根据内容再次发放。正常续玩后完成和纯旧终局导入要区分。
3. 统计／成长／解锁应形成一个校验后的档案候选，保存成功再提示；失败／重试／跨页变化保留旧资料。单键写入不是全局跨页锁。
4. 生存真人淘汰后只取真人实际参与事实及冻结分；AI后续构筑不能记给真人，完成类等正式终局；难度取局内已保存值。
5. 当前最近历史最多200条，累计与凭据独立；凭据8192、档案1MiB。不可用历史条数猜生涯，也不可将完整回放复制到成长档案。
6. 角色限制只针对新局入口；已有续玩／回放保持原角色、AI池不跟随人类解锁缩小、独立教学不计正式奖励。
