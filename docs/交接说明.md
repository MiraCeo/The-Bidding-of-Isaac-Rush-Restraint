- **文件与版本**：对局v5、growth外层1、内部schema8／catalogVersion7、profile1、独立档案文件1、容器1、库schema1和整库备份1是不同维度。未知版本拒绝并保留资料，不当空档。经典显式`classic-tiered-1`身份不能覆盖旧缺字段v5的原策略／ID。
