# 0.5 成就编号对照

日期：2026-10-16；0.5.12／总表修订6。此表仅作编号索引，名称、条件、等级及目标的唯一实时名单仍是[成就总表](./成就总表.md)。

## 编号边界

- **正式编号**：玩家界面、搜索、详情及后续讨论使用；按A～F分类，同系列铜银金相邻，分类内连续。
- **存储ID**：0.5.11以前界面使用的旧ID，也是当前代码、进度、凭据、角色前置和札记映射继续使用的稳定key。它不是本版公开编号，不能按新编号反向解释旧档案。
- 例：正式A02对应存储A08；旧退休存储A02绝不对应新A02。搜索只认新编号，不隐式兼容旧编号以免一搜两枚。
- 历史文档、快照、旧HTML不重写；查旧ID请看第二列。开发时可从`achievementNumber(id)`得到正式编号，从`achievementIdForNumber(number)`反查稳定ID，不能直接用公开编号索引进度对象。
- 原暂缓候选**旧提案B10／E13／E14／F11**未注册、没有正式编号，不占空位；将来恢复需重新分配新正式编号及从未使用的稳定ID。此处同形新编号不代表候选被实施。
- 不改变固定基线1、catalogVersion5、schema6、原始账本顺序、事实key或角色实质条件，不清零、不重发、不用现有进度倒造新等级时间。
