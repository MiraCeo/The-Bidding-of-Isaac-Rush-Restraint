## 二、C：扰乱与结算奇遇

下表ID仅指0.5.7的对象定位，不为新增等级提前分配ID。

| 基线对象 | 已确认条件／调整 | 等级与隐藏 |

| C01 鸠占鹊巢 | 累计亲自通过扰乱造成实际轮空1／10／20次 | 铜／银／金，公开 |
| C02 塞翁失马 | 累计正常竞拍失败后取得正金额屏障退款1／10／20次 | 铜／银／金，公开 |

| C04 竹篮打水一场空 | 保持首次已获资格的奖励被尾巴实际消除 | 铜，公开 |
| C05 好事成双 | 保持首次尾巴将一次奖励实际复制为两份 | 铜，公开 |
| C06 时来运转 | 累计六面骰实际触发房间积分翻倍6／18／66个房间 | 铜／银／金，公开 |
| C07 祸不单行 | 原条件不变 | 金，隐藏 |
| C08 反客为主 | 同一局在两个不同房间，分别通过超凡升天转化自己的扰乱资格，且实际取得本组道具 | 金，隐藏 |
| C09 两处空席 | 原条件不变 | 金，隐藏 |

计数口径：

- 鸠占鹊巢按真人扰乱行动所属组计数；一份行动同时占据两条路径仍只算一次；A、B两份行动分别满足可算两次。已由超凡升天赎回的名额不算轮空，不能因后续尾巴消除再倒推为扰乱轮空。
- 塞翁失马按实际取得正金额退款的正常竞拍行动计数；同一行动的多条退款事件不重复增加，退款不撤销该行动的正常竞拍失败事实。
- 时来运转每房最多一次；之后被其他效果清零不撤销翻倍事实。铜级从累计6房开始，不另保留本稿之外的“首次1房”新铜章。
- 反客为主必须是同一场、同一父分支中的两个不同房间，每房均关联本人超凡升天转化及同组真实发放；同房A、B双组不能代替两个房间，另一组获奖不能代替本组发放。
- 尾巴两项不扩阶梯，不把反复遭遇随机消除设成长线必刷目标。
