## 一、已整理及修正的问题

### 1. 条件与说明混用中文计数、阿拉伯数字

当前列表摘要、完整条件、判定细则、通用规则及无障碍计数说明统一：`1次`、`2份`、`2个不同房间`、`5名角色`、`第1层`、`第1名`、`第1级`、`4位精度`、`大于0`。句子仍使用正常中文，不把整段描述变成数字或公式。

- 保留固有名称：两败俱伤、两处空席、背水一战、六面骰、永恒六面骰等不改名。
- 保留语法指代：同一局、同一父分支、另一组、任一行动、一次性、一键等不机械改成数字。
- 保留机制术语及现有等级后缀：双竞拍／双扰乱／双行动与I／II／III不重命名；明确表示组数、路径数的描述改用2组／2条路径。
- 历史版本目录不改写，在当前目录投影层提供独立成就文案，系列沿用当前共用文案；旧判定与兼容配置不变。
- 逐项同步[成就总表](./成就总表.md)的117枚摘要／完整条件／判定说明，共核对351个字段；札记和名称未被数字替换波及。

### 2. 固定层号不能被等级目标值替换

原详情按首次出现的目标数字替换为“目标值”。中文“第一层”变成“第1层”后，过关斩将铜阶的目标同为1，直接沿用原替换会误伤固定起点。

本批只将该系列的`前1／3／5层`目标部分归并为`前目标值层`，保持`从第1层起`及金阶困难／最高限制。新增回归覆盖全部117枚描述和该边界，不涉及判定器。

### 3. 总表系列汇总仍残留旧目标

总表逐枚条件已经是现行口径，但系列汇总仍将和而不同写为1／5／20、另辟蹊径写为1／5／10。本批同步为**两者均1／10／50**，与0.6.6以来的程序和逐枚表一致。这是修正文档漏项，不是再次调整阈值。

### P1：重写前要分开“目标”与“札记”的职责

当前详情里，已获阶段的目标／进度行只有`sr-only`无障碍文本；视觉上显示札记和已达成时间，通用细则则将分级门槛归并为“目标值”。因此，带数字的模板有时意外承担了“已获阶段门槛”的可见说明，而手写短句未必有这个数字。

若直接去掉46条模板中的数字，已获阶段的目标可见性会更不一致。建议后续在每级详情保留独立、简短的目标文字，例如“累计失败20次”，札记只负责氛围。**这是待讨论的呈现问题，本批不改布局、不恢复进度条、不增独立收藏系统。**

### P2：少量札记与真实条件的含义可更贴合

| 正式编号／名称 | 当前札记或问题 | 建议方向／候选短句 |
| --- | --- | --- |
| E10 各显神通 | “同一场竞合，五种不同的自己。”容易被理解为同局操作5名角色，实际是分别完成正式对局 | “不同的面孔，已经走过各自的一程。” |
| C15 两处空席 | “两张椅子都留着，奖品却没人来领。”容易把A、B各至少1个名额空缺写成只有2个名额／全部奖励无人领取 | “A、B各空了1席，你的位置倒是占得很稳。” |
| B23 两败俱伤 | “两条路，总有一条空着回来。”略像必然规律，而条件是这次同组至少1条路径全部轮空 | 保留荒诞感，但落在本次已经发生的轮空，不写成未来保证 |
| C17 竹篮打水一场空III | “不肯空手离开”赋予玩家持续争取的意图，而触发是随机消除奖励 | 可改成更贴近反复收到空奖品的调侃；不是规则错误，优先级低于模板 |
| F15 险中求胜 | “只差一步出局”是修辞；最低存活成绩不一定紧贴斩杀线 | 可以保留惊险氛围，不进一步写成“仅差1分”等不存在的事实 |

札记允许比喻和幽默，不要求逐字复述判定。上述区分明确误读与轻微修辞风险，不把所有文学表达都当作程序错误。

### P2：阶段语气与意象重复

- 银金不应只换数字：铜偏首次遭遇，银偏熟悉／反复，金偏长期积累后的独特感受；不是统一变得夸张或保证更强。
- “路、门、故事、账本”在多条手写短句中反复出现。按主题分配：竞拍写出价／空位，资金写零钱／收支，道具写骰子／奖品，生存写关门／留下；不强行每条都写“故事”。
- 原有“请签收这份本来属于你的空气。”“战术没有问题，骰子另有想法。”“钱不是万能的，但这次确实挺好用。”等短句辨识度较好，可优先保留。
- 精确次数、金额、层数若出现在新札记里，也使用阿拉伯数字；“下一次”“一路”等普通修辞不机械替换。札记不承担判定条件，条件数字以独立目标说明为准。
