# 《以撒的竞合：冲·慎》0.5成就与角色解锁设计表

日期：2026-10-14。状态：产品设计已确认，用户在文档补全后授权正式推进0.5.0。第三批B已接正式结算成长保存、自动入账与同源协调；P1-1／P1-2已接角色权限和基础成就UI，实际验收仍待P1-3。产品条件不因分批开发改变；见[首批](../记录/0.5.0成就规则层首批实施.md)及[第三批B](../记录/0.5.0自动入账与写入协调第三批B.md)。

配套：[判定边界与旧存档迁移规则](./0.5成就判定边界与旧存档迁移规则.md)负责边界裁定，[实施计划](./0.5成就与角色解锁计划.md)负责工程顺序与验收。边界冲突以裁定文档及其R13～R19补充为准；旧交接中的待定项和早期10～15项目标／终局统一发放／旧玩家保留角色等建议已被本轮设计替代，不回写历史记录。

## 一、确定范围

- 共30项，6个主分类；A02、E01～E05共6项参与角色解锁，其余24项纯收藏。
- A～E在经典与生存两种正式模式共用达成状态及跨局累计；连续／复合条件仍限同一场对局，不能跨模式或跨局拼接。F只统计正式生存模式。
- 只给真人记账。AI可以提供市场占位等环境事实，不登记AI个人成就；独立教学不计。
- 新老玩家首次启用0.5体系均默认仅开放以撒；旧进行中局仍保留原角色，可正常继续。
- 一键解锁全部角色只开放角色，不改成就或统计，不产生对局加成。
- 对应进房、房间、层末、终局有效结算完成后，成长档案成功保存才显示已达成；随后放弃不撤销。只读查看、历史回溯和重复恢复不发奖。
- 不增加成长货币、永久资金／得分加成、道具扩池、联网或新赛制，不改变现行AI、竞拍和淘汰机制。

## 二、30项成就

### A．竞拍失败类（3项）

| ID | 名称 | 达成条件 | 记账口径 |
| --- | --- | --- | --- |
| A01 | 失败乃成功之母 | 累计正常竞拍失败1次 | 与A02共用正常竞拍失败累计 |
| A02 | 屡败屡战 | 累计正常竞拍失败10次 | 游魂前置；双竞拍分别判断两组 |
| A03 | 屡战屡败 | 同一局内连续正常竞拍失败5次 | 单竞拍失败+1；双败+2；本房有任何成功则清零；观望／扰乱保持；不按A/B顺序抢先达成 |

失败按市场获奖资格判定阶段认定，与屏障退款判定一致：有效正常竞拍未取得对应组资格。屏障退款仍是失败；取得资格后被更多选择随机舍弃或被尾巴消除，不算失败。观望和扰乱不属于正常竞拍失败。

生存真人淘汰后，后续AI的个人资金、道具和得分不计真人成长；AI终局只用于必要的整局边界确认。

## 四、明确排除与剩余讨论

- 原候选不劳而获改名为意外之喜，不再使用旧名。
- 两全其美、四两拨千斤、绝地反击、高枕无忧不在本版30项内，不自行恢复或追加。
- 隐藏成就、页面入口、提示动画及展示形式仍单独讨论。六个主分类与名称不是待定UI细节。
- 30项规则已定，不因为工程字段设计困难重新扩大或缩小条件。技术缺口及验收见[实施计划](./0.5成就与角色解锁计划.md)。
