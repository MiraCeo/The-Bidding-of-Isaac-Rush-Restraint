## 本轮重点核对的含义边界

1. A03／B09／F08用拍卖槌、观望的未领名额和淘汰名单替代抽象账本／市场发言／冒险道路，不新增策略要求。
2. C15仍须本人2份扰乱分别造成A、B未赎回名额轮空；札记不把空缺固定成恰好各1席，也不声称持续稳定占位。
3. C07只取得转化后的奖励资格，不保证道具实际交付；C17只指被尾巴消除的奖励位置，不暗示本房全部奖品栏都为空。
4. A11／C05的失败落在对应报价，不要求整房空手；C06／D17／D19不虚构可用余额或多次小额的累计过程。
5. C11只认翻倍效果，之后可以清零；E09最高分允许并列，不强求名单数组第1位；E17不把不等报价解释成商量失败；E23不额外要求玩家先检查奖品。
6. 普通修辞、道具拟人和不影响条件的情绪表达不一概删除；保留D18商店折扣、F15最低存活后夺冠等已经贴合条件的句子。
