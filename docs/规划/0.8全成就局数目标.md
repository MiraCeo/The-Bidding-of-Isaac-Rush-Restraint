# 0.8全成就局数目标：暂定25±5局

**最终状态（2026-10-21）：成就平衡已按用户要求收口，只落实久经沙场10局、久经风浪10局、坐山观虎斗1／5／10、非将军之过1／5／10（共5枚改值）。其余研究候选不实施，不再补测、调参或推进全117目标。见[最终实施与停止边界](../记录/0.8成就平衡收口与五项数值落地.md)。下文未完成项均保留为历史，不再作为当前待办。**

确认日期：2026-10-21。用户决定：**全成就局数暂定25±5，即总计20～30局左右收齐117枚。** 这是新的整体评估目标，不是本次已批准的具体阈值或条件修改。

## 当前口径

- 同一份正常新档案累计，经典与生存合计计局，不是每模式各20～30局，也不是每个金阶各需20～30局。
- 将学习、实际解锁、切换角色、跨模式与难度、针对缺项收尾纳入同一预算；不预先授予角色、道具或进度。
- 局数按现行正式对局完成身份理解；中途退出、重复恢复、只读回放不增加局数或补奖。
- 25为暂定中心，20～30为设计窗口，不新增硬保底，也不声称现有模拟已经证明真人可在此窗口全部完成。
- 经典／生存局数比例、目标玩家熟练程度及统计达标比例尚未另定，不擅自把暂定目标改成强制每个人、每种打法均保证达成。

## 对现有判断的影响

1. **优先处理硬下限**：E12久经沙场要求20局经典，F13久经风浪要求15局生存，仅两项就至少35局，超过目标上沿。必须重估这些要求，不能只调整随机金阶。
2. **再看失败与机会累计**：A10屡败屡战III的20局失利，以及吊车尾、尾巴消除／复制、隐藏奖励、六面骰翻倍等，对总20～30局预算重新评估；不能沿用各玩20局的单模式命中比例作为全收齐概率。
3. **背水／厚积加量候选暂挂**：背水1／10／40、厚积1／10／30是此前“单组金阶20～30局”定位下的候选，不再作为默认实施方向；旧数据和候选保留，正式目标仍为1／5／10、1／5／15。
4. **旧审查分类不是新目标验收**：原117项审查的4候选／49观察／62暂留／2证据不足，仅解释原定位；全部条目需按新总预算重新排序，不能宣称其余项目已符合25±5局。

## 后续验证边界

先提出次数／条件的调整对照，再用一份档案的混合模式、真实解锁与定向补缺路线核验；不得拿多条独立档案的联合覆盖当作单档全成就。总局数、资格机会、首获、未达成截尾及最后缺项应同时报告，不为追求漂亮均值而隐去超时或随机长尾。

本次只记录目标。尚未改动正式次数、条件、AI、角色前置、存储或旧进度，未启动新模拟、打包或发布。涉及旧已获、独立达成时间、解锁与未达累计的衔接，仍需在正式实施前明确。
