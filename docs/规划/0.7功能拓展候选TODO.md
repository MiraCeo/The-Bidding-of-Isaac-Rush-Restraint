## 一、版本定位与边界

- 0.6侧重界面美化、性能和可靠性收尾；0.7侧重玩家在选择、判断、对局挑战与反馈上的实际体验，而不是再做一轮全站换皮。
- 优先改善已有模式与系统，不预先增加新模式、角色、道具、永久成长或独立任务体系。
- 只读展示优化与实际AI行为变化分开验证；不能把经典难度接入伪装成“只加下拉框、无需核对规则身份”。
- 修复实施中发现的具体故障，但不以体验优化为由重新无限打磨已定稿成就总览。
