## 如何使用历史记录

1. 数据只对应报告当时的规则、人数、种子和开关，不视为现行实现说明。
2. v16 是最高价扰乱资格修正分界；v1～v15 的旧占位结论不能套用现行规则。
3. v19 的以撒完整利息方案由 v20 角色资金方案替代；v22 完整 21 人格实验由 v23 正式 20 人格池选择取代。
4. 新规则或参数产生新报告，不回写旧数据。将来出现新基线时，把被替代的旧基线移入本目录，并同步修正链接。
