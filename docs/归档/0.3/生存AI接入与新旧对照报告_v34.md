# 生存专属AI第一版接入与对照报告 v34

> 2026-10-13。应用0.3.1，正式斩杀线200／325／500／750／1050／1500／2500，生存引擎survival-client-2。经典AI与规则保持原样。此报告记录第一版启发式效果，不宣称完成角色／主义平衡或全局最优策略。

## 一、实现范围

- survival-ai-plan.ts只消费公开当层R、当前现金、上层S及活跃名单，估计绝对线下和相对末位压力；不拿累计整局房分作为当层排名。
- 过线不自动安全：参考当前末位区间和安全余量；同投影分以平均分位处理，不偷看最终同分抽签。
- 预计存活压力修正行为权重，保留主义零权重、人格以及自身预测噪声；安全领先者也并非固定观望。
- 报价估值加入实际扣款10%的余额机会成本和自身已有构筑的预计积分；骰子使用期望、清零使用风险折扣，不读取房末实际触发或新获道具。
- 预算按本房及公开未来位置分配，预留未来/BOSS资金，急迫时适度释放，第五房释放预留。未来普通房使用统计权重，不读取其真实类型或奖励。
- 报价候选先按实际扣款预算与合法名义上限拟合，再比较效用；Steam Sale按引擎实际取整处理。双行动受共同实际支出预算、预留和原名义总额限制。
- 新策略只在survivalGameReducer启用。保留decideAiTurn经典路径和显式legacy研究分支；经典10局780个完整状态固定对照通过。

## 二、数据口径

另选不重叠的200个新种子（20261213起、2批各100），同角色／策略分别跑旧AI和新AI、两条曲线，共2400条件局；与开发集逐种子集合不重叠。这组未用于再调预算权重。

所有表格只取正式递增线，三策略条件彼此配对、相关；独立世界开发600、新种子200，而非各条件局数相加。全AI20名、两个脚本19AI＋测试槽；脚本不等于实际真人操作。
