# 生存正式入口与首版预设 v1

> 2026-10-13，当前应用开发预览0.3.3。三类榜单、实时分层显示、四档难度及正式递增线已接入；下文“为何首版选择250”为0.3.0历史记录，不是当前默认。正式入口指可实际开局，不代表云发布或完成角色／主义平衡。

结算页“积分排行”展示已结算房间积分、行动与道具，“争夺榜”展示本房A/B市场争夺；顶部排行默认生存榜，三类可切换。尚未结算房间时隐藏本房积分／争夺结果。生存榜显示玩家、状态、已发生各层与累计：当前层只加已结算R，层末使用新增积分R＋兑换，S独立提示，不重复继承；淘汰后后续层为未参与。进入下一房／层恢复正确阶段，不误套经典最终排行文案。

生存选角页增加简单／标准／困难／最高，默认标准。难度在开局后锁定，恢复按原档位，回放／文件预览显示来源难度；最高保留原0.3.1。斩杀线、资金、奖励和淘汰规则四档相同。旧client2无难度对局继续原最高，client1仅只读。首轮分档配对研究见 [v35](./生存AI难度分层与配对测试_v35.md)。下段AI2强度数据是最高基线历史，不代表当前默认标准的统计。

## 入口与状态

当前正式斩杀线为**200／325／500／750／1050／1500／2500**，第一版专属AI按当层生存分和末位压力决策，预留未来房间／BOSS资金并计算实际现金兑换机会成本。600原种子＋200新种子对照中，全AI平均结束层约6，已经不同于旧AI下的约4.39层；详见 [v34](./生存AI接入与新旧对照报告_v34.md)。经典不变；旧生存回放只读、旧引擎检查点不混新AI续玩，原数据保留。

- 初次打开主菜单：教程、经典、生存。旧经典活动存档仍能直接恢复原局。
- 仅进入选角、教程、规则、设置不创建正式生存世界；选择角色并开始才初始化。
- 经典和生存会话分别保留，返回主菜单切换不会丢弃报价草稿。重新选角必须确认放弃当前局；已完成局可直接再来一局。
- 生存：20人开局，每层5房，基础资金1000，第5房BOSS，使用普通BOSS奖励池。角色和道具经济在基础资金之后应用。
- 采用上述七层递增线，不开放参数编辑；旧250首次试跑已替换。取消黑王子之冠，包括真人和AI伊甸开局随机池。
- 本房沿用报价操作、金额合法性、四金额预览及房间结算。层末展示R、10%兑换、20%继承、生存分和淘汰原因。
- 每层至少淘汰2人；剩余≤6人结束，允许超额淘汰；团灭没有冠军。完整20人总榜按存活、淘汰层数、累计新增积分排序，种子决胜。存活状态显示“存活”。
- 玩家出局后个人状态冻结，页面分步自动执行AI-only房间及推进，不伪造真人观望。切到菜单或设置仍继续；异常保留状态、显示错误并允许重试。
- 公开排行只使用当前状态与已完成层的积分，不在部分房间结束时提前宣告达标。

## 文件与进度

两种模式的设置都可读经典v2/v3、生存v4；先校验预览，再明确确认。旧经典对局不会被转换成生存。

生存检查点包含当前位置、草稿与可验证命令；独立事实回放只读已结算房间／层／总榜。完整备份嵌入相互一致的检查点与回放，再附独立玩家档案。导入备份默认不恢复玩家进度。

自动存储各用独立键。读取失败保留原文；配额不足或存储不可用仍可在本页操作并导出。最近完成生存回放在生存设置中独立读取。

生存完成局在玩家档案轻量历史里记录模式、实际序数排名、累计分、存活／淘汰层数。完整事实的SHA256身份排除构建标签，防止刷新／重复载入重复计局。只读回放不会登记。没有新增解锁、成就奖励或成长规则。

## 为什么首版选择250

运行器：[survival-entry-calibration.report.test.ts](../../../web/lib/game/survival-entry-calibration.report.test.ts)。研究输入：60个固定种子与角色配对，5角色轮换；每个世界比较3条斩杀线与2种固定真人脚本，共360个**条件对局**，不是360个独立世界。

真人脚本：全观望；按剩余房数均分现金、A/B交替竞拍，不具备自适应构筑策略。所有条件沿用当前启发式AI。

| 斩杀线 | 真人脚本 | 平均层数 | 中位层数 | P90层数 | 团灭 | 真人存活 |
|---|---|---:|---:|---:|---:|---:|
|150|观望|6.6667|7|7|0/60|0/60|
|150|均摊竞拍|6.8333|7|7|0/60|10/60|
|200|观望|6.0500|6|7|0/60|0/60|
|200|均摊竞拍|6.4833|7|7|0/60|9/60|
|250|观望|5.1500|5|7|0/60|0/60|
|250|均摊竞拍|5.7333|6|7|0/60|12/60|

250在这些样本中减少接近七层的长局，同时未出现团灭，因此作为首版试跑预设。这些数据不能证明难度、公平性、角色强弱或道具生态已经合格，也不能证明其他种子不存在团灭。

复现：在web目录设置`SURVIVAL_ENTRY_STUDY=1`，执行`npx vitest run lib/game/survival-entry-calibration.report.test.ts --maxWorkers=1`。需要已有work目录；输出`web/work/survival-entry-calibration.json`，默认测试不运行批量报告。

## 当前边界

后续分数测量已完成：[不淘汰分数v29](./模拟报告_生存不淘汰分数与斩杀线范围_v29.md)。3批600独立世界、3条件1800局的全20人基线表明250首层压力较高、后续多依赖末位补淘汰。支持先探索首层150—250及递增分层线；本节上方250选择过程保留为入口试跑历史，正式250尚未改动，真实淘汰候选验证待做。

用户确认候选线200／250／325／425／550／700／850后的真实淘汰测试见 [v30](./模拟报告_生存递增斩杀线与AI诊断_v30.md)。与固定250配对3600条件局，候选全AI平均5.96层结束、31.7%到第7层，后层仍以补淘汰为主；测试完成，不表示已采用候选线或调整AI。其他候选与AI消融未执行。

第二条150／225／325／475／650／850／1100／1500研究见 [v31](./模拟报告_150起步递增斩杀线测试_v31.md)。按现行七层上界实际仅使用前七项，1500不生效；全AI平均6.18层，38.5%第7层结束。正式入口仍固定250，AI未改。

第三条200／325／500／750／1150／1800／2500研究见 [v32](./模拟报告_200起步高增幅斩杀线测试_v32.md)。全AI平均4.36层，第四／第五层结束占83.3%，团灭观察2/600；线下淘汰成为主要压力。末层2500仅两个脚本条件局到达，不能冒称已充分验证。仍只测，不采用新曲线或修改AI。

第五层1050、第六层1500微调见 [v33](./模拟报告_第五六层斩杀线微调测试_v33.md)。同世界全AI平均4.39层、最终人数4.79，团灭观察0/600，但脚本各1/600仍有团灭。当前曲线仅研究，不替换正式250；AI未改。

- 第一版已接入斩杀线压力、相对末位、继承和兑换机会成本目标，并完成新旧AI及独立新种子对照；角色／主义适配和后续预算消融仍未完成，不宣称最终平衡通过。
- 生存回放先提供事实选择、金额／评分原文、市场／奖励原文、各层分项及总榜；不宣称已经复刻经典三视图图表与压缩编码。
- 教程沿用独立五课，生存专项教学待补充。
- 本轮普通网页进行实际UI检查；直接file离线完整验收、移动端、容器和云端验收另列，不用HTTP检查替代。
