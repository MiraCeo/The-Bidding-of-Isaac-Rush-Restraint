偏差是额外系数而非总误差，原人格、主义与报价随机性继续存在；四档共同使用原实际预算上限，取整后重新合法拟合，误差不会透支现金。生存干预系数控制紧迫性行为乘数、相对生存排名与累计排名混合、候选附加生存效用；不把内部预期分数改成正式层末分。低档误差按种子／玩家／房间另派生，不写入长期人格或报价档案，不读取他人秘密行动和未来奖励。

最高不保证每个种子每个指标都强于其他档。多人市场、奖励和淘汰名单会相互改变；难度是决策精度分层，不是胜率强制控制器。
