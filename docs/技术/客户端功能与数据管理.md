# 客户端功能与数据管理

当前0.5.7已接成就记账、角色权限与基础展示；本地打包与自动化通过，实机验收仍待用户单独授权。本文为现行使用入口，不复述每次实施／验证过程。旧“四导航、设置存档、三进度分类”说明已归档。

## 五个主导航

| 入口 | 当前职责 |
| --- | --- |
| 游戏 | 选角／真实对局阶段、报价、结算、推进、明确重新选角 |
| 排行 | 公开积分／资金；结算后的积分／争夺；生存另有实时／终局生存榜 |
| 进度 | 总览、对局记录、统计、成就、存档与备份 |
| 设置 | 积分显示精度、面板默认展开、动效、恢复默认显示、版本与反馈 |
| 规则 | 当前规则、道具查询、进入独立教学 |

顶部稳定显示产品名称，页面名在内容标题。角色胶囊可打开构筑；独立只读回放使用用途标题，不伪装正在进行的对局。

## 进度的五个分类

- **总览：**两模式当前局卡、真实保存状态、继续／查看终局或进入选角。不是多存档槽。
- **对局记录：**本局／最近可用回放、最多200条轻量完成记录，以及IndexedDB长期完整回放库。完整库可筛选、导入、导出、明确删除、经典等价副本只读核对；整库备份／恢复也在这里，不受当前筛选截断。
- **统计：**完成登记启用后的累计，按模式／角色／生存难度筛选。累计不等于最近200条记录；不反推已丢失的旧总数，只读或重复恢复不加局，删回放不减成绩。
- **成就：**六类87枚徽章／57卡条件、已保存进度／达成时间、角色前置。跨模式共享视图，同局型展示已记录的单局最高值；一键授权角色不将成就全部勾为完成。
- **存档与备份：**续玩、回放、本局完整备份及导入预览，独立玩家档案备份／恢复和默认折叠的只读存储诊断。

内部模式筛选只决定展示记录，不改变来源对局、活动模式或顶部资金。选择“继续某个模式”才明确切换。

成就含15组单卡三级，搜索可用任一子ID；每级有独立条件／时间／札记，部分完成聚焦下一等级。游魂新前置为非将军之过＋屡败屡战I（5局正式终局第6及以后），旧权限保留；旧A02／A04单列纪念不计当前总数。五项按A／B组数统计，缺失旧组数／排名不倒推；全部口径见[成就总表](../规划/成就总表.md)和[0.5.7记录](../记录/0.5.7AB成就阶梯与旧档迁移.md)。

## 返回与隔离

浏览设置／进度／规则／构筑不提交行动，不重新运行已结算房间，不重新创建正式局。选角、草稿、真实阶段保留；真人淘汰后的AI续赛继续运行，完成后更新档案与记录。

从进度打开回放返回原分类／模式。Esc优先退出当前预览／任务，再返回来源；取消或离开后异步迟到结果不能覆盖资料或触发下载。重新选角是游戏生命周期操作，需明确确认；需要保留先到进度→存档与备份导出续玩存档。

设置的“恢复默认”仅恢复显示偏好，不重置角色、种子、资金、道具、档案或回放库。偏好与对局各自保存。

## 回放

经典按本房复盘／整局概览查看个人计分链、市场、全场明细与事件。生存增加层末结算／生存总榜；尚未发生或未结算的范围不提供虚拟事实。支持查看玩家、房间目录和积分／资金走势；淘汰后只画实际参与房间，分数冻结。

全场明细与宽图使用内部滚动，表头保持固定；玩家按钮仍能切换个人复盘。回放只读、不运行AI、不替换当前局、不登记新的玩家成绩。

详细显示依据：[经典回放层级](./回放界面层级与图表_v1.md)、[生存回放](./生存回放界面完善_v1.md)。

## 文件与进一步阅读

五类文件的范围／确认／失败语义见[存储与恢复边界](./存储与恢复边界.md)，字段与兼容边界见[当前协议v5](./当前文件协议_v5.md)。本机存储失败与文件读取失败分别提示，原资料保留，不因目录整理新增迁移或清空。

0.5默认以撒，其他角色按固定成就解锁；一键授权只改角色权限。角色限制仅检查正式新局，不阻止合法旧局续玩、教学或AI。保存后提示可关闭，普通重载和只读导入不反复弹旧达成。
