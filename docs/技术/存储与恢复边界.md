# 存储与恢复边界

当前开发预览0.5.0第二批，原对局存储／恢复路径保持。独立成长模块已实现后台严格校验、去重与保存协调接口，但尚未挂接正式生命周期及迁移。本文集中说明已实现的数据职责，不作为新协议、不改变原恢复路径。

## 数据各归其位

| 数据 | 作用 | 边界 |
| --- | --- | --- |
| 经典／生存自动检查点 | 各一份续玩位置和草稿 | 两模式分开；不是多存档槽，自动存储未压缩 |
| 最近完成回放 | 各模式最近完成局的原事实 | 不是长期全量库，归档失败与检查点失败分别处理 |
| 轻量完成历史 | 档案中最近最多200条结果 | 不承诺都有完整回放，不代表终身总数 |
| 完成累计与去重凭据 | 登记启用后的基础统计 | 重复恢复／只读查看不增；旧丢失历史不猜回填 |
| 玩家档案 | 完成记录、累计／凭据与已保留扩展数据 | 两模式共享，与显示偏好和完整库分开 |
| 0.5后台成长账本 | achievementRegistryV1紧凑结算凭据、手动角色授权及可推导进度 | 需显式启用；当前正式对局尚不写入；2048凭据／896KiB模块及整档1MiB各自有界，旧数据读取不自动发奖 |
| 完整回放库 | IndexedDB原正文、索引、首次来源与删除证据 | 默认100局／64 MiB应用上限，满库停止新增、不自动淘汰 |
| 显示偏好 | 精度、默认面板与动效 | 恢复默认不重置任何游戏数据 |

存储受浏览器／来源限制，换协议、地址、浏览器或文件路径不承诺共用资料；移动程序或切换环境前另行导出需要的数据。诊断的文本大小不是物理磁盘或通用剩余配额。

## 五类可携带文件

| 文件 | 包含 | 确认后的行为 |
| --- | --- | --- |
| 续玩v5 | 一局检查点、命令／事实与草稿 | 严格核验后载入；不默认替换档案 |
| 回放v5 | 一局已发生事实，可为进行中片段 | 只读；不变成当前局、不运行AI、不重复登记 |
| 本局完整备份v5 | 一局检查点、配套回放、本机档案快照 | 默认只载入局；替换档案需明确勾选，来源变化需重新核对 |
| 独立档案文件v1 | 完成历史、累计／凭据、已保留扩展数据 | 明确替换档案，首版不自动合并；不包含两模式续玩、完整库或设置 |
| 整库备份v1 | 两模式全部原正文、索引、首次来源、旧／新删除证据 | 核对新增／重复／删除保护后原子增量追加；不包含续玩、档案或设置 |

对局读取仅当前v5，旧v2／v3／v4拒绝，不自动迁移或删除旧资料。压缩容器仍v1，当前原JSON与压缩.json自动识别；用途按内部mode／kind判定，不按文件名猜。档案正文1、独立文件1、容器1、库schema1、整库1是不同版本维度。

单份对局8 MiB与整库文件160 MiB、正文64 MiB／100份、元数据16 MiB／8192标记分开有界，不把整库限额放宽到普通对局。

## 数据保护

- 读取先预览，确认才安装。取消／换文件／离开后丢弃迟到结果，旧候选主动释放，不请求迟到下载。
- 本局完整备份默认不替换档案；勾选后档案原文变化会阻止旧预览替换，重新核对需重新勾选。
- 配套检查点／事实／草稿／档案先写成功再切换内存；失败回滚不覆盖其他页面新写的数据。不是跨页面全局锁或崩溃日志。
- 整库恢复核对三个store未变后单次原子追加。本机首份正文／来源不覆盖，本机已删除记录不自动复活，备份内标记不删除本机存活记录。
- 经典等价去重仅限定权威事实与可核验的说明邻居，保留旧物理键／首次正文与来源；已有副本只读标注、不自动删。旧无说明删除标记仅按原键保护。
- 生存淘汰后积分／参与记录冻结，不用新默认AI或新参数重建旧局。内部AI身份与文件头版本不是同一件事。
- 已存在的成长模块严格校验，坏／未知模块保留原文不重置；没有模块的旧档案只读不自动初始化。新保存协调接口尚未覆盖原完成／恢复写入，不宣称全部跨页写入已串行化。
- 全库核验显示真实阶段，取消在边界响应；单次同步JSON片段不保证即时取消，不以提速名义跳过核验。
