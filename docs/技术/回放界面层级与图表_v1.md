## 一、先选范围，再选本房视角

| 范围 | 导航 | 展示内容 |
|---|---|---|
| 本房复盘 → 个人复盘 | 左侧房间目录；上一房／下一房；查看玩家 | 该房所选玩家的积分、资金、获奖、结算后库存与市场位置 |
| 本房复盘 → 全场明细 | 共用同一房间目录；关注玩家 | 该房20人结果对比、奖励最终分配、原行动及资格表 |
| 整局概览 | 没有单房目录、上一房／下一房或本房子标签 | 所选玩家全局汇总、逐层表现、全部已结算房间轨迹与终局排行 |

范围切换位于对局信息栏，个人／全场子标签只属于本房工具栏。工具栏压为两行：第一行房间标题／上一房下一房／玩家选择，第二行个人或全场标签／范围说明；删去重复英文眉题及大段说明。通过ResizeObserver记录实际高度，导航、焦点和房间点跳转按该高度留出滚动避让，不再把落点放在固定栏后。切换到整局不再以`F1-R1`等单房标题包装整局数据；回到本房保留原房间和子视角。整局轨迹点击某房才明确进入该房个人复盘。全场明细下换房保留全场视角及图表指标。

定位复制、定位／构建折叠项、档案构建说明和终局构建尾注已从回放界面删除。原定位、规则和构建元数据仍在JSON中保留，不改写历史文件或反馈指纹。

## 二、个人复盘的具体排布

1. **实际行动胶囊：**只列本房所选玩家实际提交的行动。
2. **摘要首行：**最终房间积分在左，资金变化居中，实际获得在右。
   - 积分卡内显示最终分、累计分、原始分与追溯追加；卡内按钮展开横跨整行的计分区域，五步链横排、细项按行动分组，不再把积分卡拉成长列。三张摘要卡等宽、等行高，右侧不为展开内容虚增高度。
   - 资金卡保留入房／结算资金、扣款、返款、其他变化与换层说明。
   - 获奖卡只展示自己实际获得的道具及副本，附屏障变化。
3. **摘要第二行：**默认展开“现在拥有的道具”，明确为所选玩家在本房结算后的快照，不是实时对局的当前库存。按ID聚合实际份数，本房新实例显示“本房 +N”；不叠加道具保留真实副本数量。
4. **市场位置：**A／B并列，每个目标一张共同数轴图，同时显示高价边界与合作区。
5. **本房关键事件：**默认折叠，仅含所选玩家及相关转移。全场原始事件移到全场明细。

个人复盘不再包含“奖励最终去了哪里”或整局终局排行，避免个人、全场和全局内容相互穿插。

## 三、市场图的两种口径

- **实心标记：市场等价。**用于高价占位边界。
- **空心标记：原始计分等价。**用于合作区判定。
- **道具实际计分取值：**单独列数，不拿它替代合作资格输入。

两种等价用同一个数轴。数值相同只画一枚标记，不同时用短线连接实心／空心位置，不能把市场等价当作合作判定。背景蓝带为合作区，金色虚线为高价边界，基准线单独标注。竞拍为圆点、扰乱为方点，所选玩家显示光圈、姓名和数值；错层避免区间重叠，保留每份行动。双行动分别出现在A／B，观望不伪造零报价。全场观望则显示无基准线状态。

下方直接列名义报价 → 市场影响／合作判定／实际计分取值，并用**原记录**标明高价／合作占位。蓝带表示区间，不承诺领奖；资格与发放另看全场结果。基准线与合作区来自历史事实，不调用当前结算算法。

## 四、全场明细的具体排布

1. **本房结果柱状图：**一人一根柱，默认本房积分，可切换累计积分／结算资金。累计积分用灰色入房已有积分与金色本房新增积分堆叠，最终高度为保存的结算后累计；新增包含追溯追加。资金用灰色行动前轮廓与较窄的青色结算后实心柱重叠，不把前后两值相加。排序和并列排名始终按结算后值，纵轴覆盖前后两值；关注玩家仅用描边／文字突出，不覆盖语义色。悬停和键盘聚焦可读前值 → 后值、净变化及实际扣款／返款／其他变化。
2. **奖励最终去了哪里：**A／B并列展示目标图标、实际获奖人数／份数和所有获得者；点击名字进入其本房个人复盘。附真实占位／资格数量及复制／毁奖原因，不把占位当作实际发放。
3. **20人行动与结算表：**保留报价、入房／结算资金、原始／追溯／最终房分、累计积分与获得道具。表头固定，长表区域可滚动。
4. **展开依据：**全场占位／资格／发放表保留特殊结果；全场事件另折叠，默认按玩家条目展示，关注玩家排首位并展开，其他收起。每个条目给出扣款／返款／本房积分／获奖摘要，摘要与积分事件金额遵守2／4位显示偏好，已知事件句式同步格式化；“精确记录”保留原文与权威数值，未知历史文本不机械重写。展开后再按进入本房 → 提交与结算保留阶段内顺序。无事件玩家只显示紧凑空态。支持展开全部、收起全部和原始顺序查看。关联转账在双方条目显示同一个原始事件编号，总事件数不重复计算。

柱状图描边标明关注玩家，悬停或聚焦展示精确值及并列名次；点选进入同房个人复盘。时序图使用稳定的玩家颜色，支持显示全部／仅看关注及逐人开关；点击曲线或榜单关注玩家，点选该线的房间点进入对应历史复盘并聚焦标题。每个折点直接读取保存的累计积分，不用逐房得分重新求和，不包含终局王冠倍率。点之间直线仅用于观察趋势，不代表有额外结算或产生新的数据点。相同数值不随机破同分，全零数据也有有限坐标。

## 五、整局概览与走势操作

整局概览依次展示：所选玩家总积分／扣款／返款／获奖 → 三层表现卡 → 全场累计积分走势 → 所选玩家资金走势 → 终局排行。累计走势复用可缩放直线组件，提供全部／仅看关注与逐人筛选；本房全场明细不再包含整局曲线。

- 参考房间单独下拉选择，竖线与右侧榜单对应该时点；切换参考房间仍留在整局，点选真实房间点才进入个人复盘。
- 资金走势每层一个独立路径，前后楼层绝不连线。空心点为保存的该层初始资金，实心点为各房结算资金，换层以断线及“重置N”标注；初始值缺失时只使用实际入房资金并标明“入房”，不臆造角色资金。
- 积分／资金轴使用1、2、5系列整洁步长，坐标上界覆盖权威原值；精确数据、排序、并列名次及显示偏好不受坐标刻度影响。

### 走势缩放操作

- 工具栏：放大／缩小／重置视图／定位参考房间；放大优先围绕参考房间，参考房间不在视窗时围绕视窗中心。
- 起点／终点滑杆：按真实房间步进，包含入场；最小跨度为2步，少于2房时使用实际跨度。短局不补未来房间。
- 图内滚轮缩放，拖动水平平移；Shift＋滚轮或水平滚轮平移。只接管绘图区内滚轮，图外正常滚页，Ctrl／Meta保留浏览器页面缩放。
- 纵轴按可见玩家及区间的真实点（含边界邻点）自动适配。参考房间、关注玩家和右侧该房时点排行榜不随缩放改变；参考房间移出视窗会提示，可一键定位。
- 仅实际可见房间点可以进入复盘；拖动超过5像素后抑制随后的鼠标点击，避免误跳。后续独立点击和键盘Enter／空格仍有效。
- 资金前值取`settlement.playersBefore`，已经包含入房效果及换层重置；不是上一房资金。返款、转移或项圈恢复可能使资金不变或增加，净减少不能当作实际扣款。
